# zero-ai-study Web（学习看板）

React + TypeScript + Ant Design + Vite + SCSS

## 安装与启动

```bash
cd zero-ai-study/web
pnpm install --registry=https://registry.npmmirror.com
pnpm dev
```

浏览器打开：http://localhost:5173  
开发期 `/api` 代理到后端 `http://127.0.0.1:8000`。

## 页面

- `/` 总览
- `/steps` 学习步骤状态
- `/runtime` 环境与数据检查
- `/effects` 执行产物效果
