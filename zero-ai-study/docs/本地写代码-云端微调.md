# 本地写代码 + 云端 GPU 微调（怎么一步步来）

> 核心原则：**本机写程序 / 改数据 / 记笔记；真正训练用别人给的免费 GPU（优先 Kaggle）。**  
> 本机没有大显卡也能学完第一轮。

---

## 分工一张图

```text
本机（你现在这台电脑）              云端（Kaggle / Colab）
─────────────────────              ─────────────────────
写 / 改 JSONL 数据          →      上传数据集
改 Notebook / 脚本草稿      →      粘贴或同步后 Run
填概念笔记、看看板          →      （不需要 GPU）
保存 outputs/ 适配器  ←─────      训练完 Download
Ollama 试聊（可选）   ←─────      导出 GGUF（可选）
```

**不要指望：** 在本机 `conda base` 里直接训 7B/8B（除非你有够用的 NVIDIA 显存）。  
**要指望：** Kaggle P100 / Colab T4 + Unsloth QLoRA。

---

## 你现在按这个顺序做（今天就能开干）

### 第 1 步：本机准备账号与 Token（约 15 分钟）

1. Hugging Face 注册 → 创建 **Read** Token：https://huggingface.co/settings/tokens  
2. 在 `zero-ai-study/`：

```bash
cd zero-ai-study
cp .env.example .env
# 编辑 .env，填入 HF_TOKEN=hf_...
```

3. （可选）看板看进度：前端 http://localhost:5173 ，把 Step 0 标成「进行中」

### 第 2 步：打开别人给的服务器 — 优先 Kaggle（约 10 分钟）

1. 登录 https://www.kaggle.com/（账号 `coolrabbit1993`）  
2. **Create → New Notebook**（或打开已有 `zero-notebook`）  
3. **先完成手机验证**（未验证时右侧往往看不到 / 选不了 GPU）：  
   头像 → **Settings / Account** → **Phone Verification** → 验证手机号  
4. 打开 Notebook 后找 Accelerator（新版 UI 常见位置）：  
   - 右侧边栏 **Settings** / **Session options**（齿轮或三条杠）  
   - 找到 **Accelerator** → 选 **GPU**（P100 或 T4 x2）  
   - 会话会重启一次  
5. Add-ons → Secrets → 新建 `HF_TOKEN`，粘贴你的 HF Token  
6. 确认右上角/侧栏能看到 GPU，再开始写代码  

Colab 作备选：https://colab.research.google.com/ （遇 503 就换回 Kaggle）

### 第 3 步：本机先把「数据」写好（不需要 GPU）

1. 打开 `datasets/sample_alpaca_zh.jsonl`  
2. 按 `02-data/README.md` **追加至少 5 条**你自己的问答  
3. 本机校验：

```bash
cd zero-ai-study
python 02-data/validate_dataset.py
```

格式每行一个 JSON：`instruction` / `input` / `output`。

### 第 4 步：云端「最快跑通」一次（先别管自己的数据）

目标：证明 GPU + Unsloth + HF 通路是通的。  
**不要自己在 GitHub 里翻文件挑 Notebook**，直接用官方「一键打开 Kaggle」链接。

#### 4.1 选哪一个？（已替你选好）

入门首选：**Llama 3.1 (8B) Alpaca SFT（Kaggle 版）**

直接打开：  
https://www.kaggle.com/notebooks/welcome?src=https%3A%2F%2Fgithub.com%2Funslothai%2Fnotebooks%2Fblob%2Fmain%2Fnb%2FKaggle-Llama3.1_%288B%29-Alpaca.ipynb

备选（7B）：  
https://www.kaggle.com/notebooks/welcome?src=https%3A%2F%2Fgithub.com%2Funslothai%2Fnotebooks%2Fblob%2Fmain%2Fnb%2FKaggle-Qwen2.5_%287B%29-Alpaca.ipynb

列表页：https://unsloth.ai/docs/get-started/unsloth-notebooks

#### 4.2 导入到你自己的 Kaggle（逐步点）

1. 登录 https://www.kaggle.com/（账号 `coolrabbit1993`）
2. 点上面的链接
3. 点 **Copy and Edit**，保存成自己的 Notebook（可改名 `zero-unsloth-llama31-8b`）
4. Settings → Accelerator → **GPU T4 x2**
5. Settings → **Internet = On**
6. Secrets 确认已有 `HF_TOKEN`
7. 最上方新增单元格并 Run：

```python
import os
from kaggle_secrets import UserSecretsClient
os.environ["HF_TOKEN"] = UserSecretsClient().get_secret("HF_TOKEN")
from huggingface_hub import login
login(token=os.environ["HF_TOKEN"])
```

8. 搜索 `max_steps`，改成 **60**
9. **Run All**，等跑完；有 loss 打印且无致命报错 → 通路成功

参考：https://unsloth.ai/docs/zh/kai-shi-shi-yong/fine-tuning-llms-guide.md

### 第 5 步：换成你本机写的数据再训一轮

1. Kaggle → 把 `sample_alpaca_zh.jsonl` **Upload** 到 Notebook，或做成 Dataset 挂载  
2. 把数据加载改成读你的文件，例如：

```python
from datasets import load_dataset
dataset = load_dataset("json", data_files="/kaggle/input/你的路径/sample_alpaca_zh.jsonl", split="train")
```

（具体路径以 Kaggle 左侧 Input 显示为准。）

3. 再跑一小段 steps，保存 LoRA 适配器  
4. **Download** 到本机：`zero-ai-study/outputs/`（已 gitignore，别提交大文件）  
5. 在 `03-finetune/finetune_run_log.md` 记下模型名、steps、大概 loss  

### 第 6 步：看效果 + 记进度

1. 用 Notebook 里推理单元格对比几句问答，或本机加载适配器  
2. 填 `04-eval/eval_log.md`  
3. 看板里把对应 Step 标成「已完成」

## 「本地写程序」到底写什么？

| 本地可以写 | 本地暂时别硬写死 |
|------------|------------------|
| JSONL 数据、校验脚本 | 完整训练循环（应在云 Notebook 跑） |
| 数据处理小脚本 | 依赖本机 CUDA 的 Unsloth 安装 |
| 从官方 Notebook 抄改后的 `.py` / `.ipynb` 草稿 | 大模型权重下载到仓库里 |
| 评估问题列表、实验记录 | — |

**推荐习惯：**

1. 本机改好 `datasets/*.jsonl` 和 Notebook 草稿（可放 `03-finetune/`）  
2. 复制到 Kaggle 再跑  
3. 产物只留在 `outputs/` 或 HF Hub，不进 Git  

以后若要更顺：可用 GitHub 私有仓库在 Kaggle `!git clone`，或 Kaggle Dataset 同步数据。
