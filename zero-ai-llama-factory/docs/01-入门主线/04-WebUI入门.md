# 04 · WebUI 入门

## 本章目标

弄清 WebUI 四个页签的职责，以及一次「LoRA SFT → 对话试效果」在界面上怎么走。  
**无本机实操时：记住流程与必填项即可**；真正点击「开始」留到云端。

## 核心概念

安装完成后启动：

```bash
llamafactory-cli webui
```

WebUI 主要四块：

| 界面 | 做什么 |
|------|--------|
| 训练 | 选模型、阶段、微调方法、数据集与超参，点开始 |
| 评估与预测 | 指定模型 + adapter，在数据集上评估/预测 |
| 对话 | 加载模型（+ adapter）聊天，直观看效果 |
| 导出 | 合并/导出（可含量化相关选项） |

## Step by step

### Step 1：进入训练页，填最小必要项

按官方说明，训练前至少想清楚：

1. **模型名称及路径**（HF id 或本地目录）
2. **训练阶段**（入门选 SFT）
3. **微调方法**（入门选 LoRA）
4. **训练数据集**（先用自带 demo，如 `alpaca_zh_demo` / `identity`）
5. **学习率、训练轮数**等（先用界面默认或保守值）
6. **LoRA 相关参数**（rank 等可先默认）
7. **输出目录**（每次实验用不同目录，方便对比）

然后点击 **开始**。

### Step 2：观察训练过程

- 关注 loss 是否总体下降、是否立刻 OOM。
- 适配器 / checkpoint 会落在你设的 **输出目录（output_dir）**。

### Step 3：断点续训（需要时）

- Checkpoint 在 `output_dir` 下。
- 续训时指定 **适配器路径**，加载断点继续。

### Step 4：自定义数据

- 先按 [03-数据准备.md](03-数据准备.md) 写好数据并注册。
- 再在 WebUI 数据集列表中选择你的数据集名。
- 格式不对会导致训练失败。

### Step 5：对话页快速验货

训练结束后：

1. 打开 **对话** 页
2. 指定 **模型**、**适配器**、**推理引擎**
3. 输入几句与训练分布相近的问题，看是否学到风格/知识

### Step 6：评估与导出（可选）

- **评估与预测**：对指定数据集跑评估。
- **导出**：对效果满意后再导出；合并 LoRA 时注意不要用错量化基座（详见第 06 章）。

## 建议的「第一次训练」保守配置直觉

| 项 | 入门建议 |
|----|----------|
| 模型 | 显存允许下的较小 Instruct 模型（如 3B～8B 量级） |
| 方法 | LoRA |
| 数据 | 官方 demo，或你的小样本 |
| 序列长度 | 先 1024～2048，显存紧再降 |
| batch | `per_device` 先 1，靠梯度累积凑有效 batch |
| epoch | 1～3，先求跑通 |

具体数值因卡而异；OOM 就降 `cutoff_len`、batch，或改用 QLoRA（进阶章）。

## 检查点

**概念过关（当前）：**

- [ ] 能默写四页：训练 / 评估与预测 / 对话 / 导出
- [ ] 能列出训练页最少要填的几类参数
- [ ] 知道自定义数据必须先写入数据集描述文件
- [ ] 知道断点在 `output_dir`，续训要指定适配器路径

**实操过关（以后）：**

- [ ] `llamafactory-cli webui` 能打开界面
- [ ] demo 数据训练产出落在 `output_dir`
- [ ] 对话页能加载 adapter 聊天

## 常见坑

- 模型路径填错 / 权限不足 / 下载中断。
- `template` 与模型不匹配。
- 自定义数据集未注册或 JSON 错误。
- 续训时指错 adapter 路径，或之前 `save_only_model` 导致无法完整 resume（见第 06 章）。
