# 07 · 推理

## 本章目标

掌握三种常用推理方式：命令行 chat、WebChat、以及 API / 批量推理；能加载「原模型」或「原模型 + LoRA」。

## 核心概念

入口示例：

```bash
llamafactory-cli chat examples/inference/xxx.yaml
llamafactory-cli webchat examples/inference/xxx.yaml
```

默认推理后端多为 Hugging Face Transformers；可设 `infer_backend: vllm` 追求更高吞吐（需安装 vLLM）。

**硬约束：** `model_name_or_path` 存在，且与 `template` 对应。

## 配置模板

### 原始模型

```yaml
model_name_or_path: Qwen/Qwen3-4B-Instruct-2507
template: qwen3_nothink
infer_backend: huggingface   # 或 vllm
trust_remote_code: true
```

### 微调模型（LoRA）

```yaml
model_name_or_path: Qwen/Qwen3-4B-Instruct-2507
adapter_name_or_path: saves/qwen3-4b/lora/sft
template: qwen3_nothink
finetuning_type: lora
infer_backend: huggingface
trust_remote_code: true
```

若已 merge，可只填合并后的 `model_name_or_path`，不必再填 adapter。

### 多模态

使用对应 VL 模型与 `template`（如官方 `qwen3_vl` 示例），常用：

```bash
llamafactory-cli webchat examples/inference/qwen3vl.yaml
```

## 批量推理

### 数据集 + vLLM 脚本

```bash
python scripts/vllm_infer.py \
  --model_name_or_path path_to_merged_model \
  --dataset alpaca_en_demo
```

### OpenAI 兼容 API

启动（端口等可按环境变量调整）：

```bash
API_PORT=8000 CUDA_VISIBLE_DEVICES=0 \
  llamafactory-cli api examples/inference/qwen3_lora_sft.yaml
```

调用示例：

```python
from openai import OpenAI

client = OpenAI(api_key="0", base_url="http://0.0.0.0:8000/v1")
messages = [{"role": "user", "content": "Who are you?"}]
result = client.chat.completions.create(
    messages=messages,
    model="Qwen/Qwen3-4B-Instruct-2507",
)
print(result.choices[0].message)
```

## Step by step

1. 先对 **未微调基座** 跑一次 `chat`，确认环境与 template 正常。
2. 加上 `adapter_name_or_path`，对比同一问题的回答变化。
3. 需要给别人调用时，再开 `api`。
4. 需要大规模离线生成时，用 `vllm_infer.py` 或 `infer_backend: vllm`。

## 检查点

**概念过关（当前）：**

- [ ] 会在纸上写出最小 inference YAML
- [ ] 能区分「基座」「基座+adapter」「merged」三种加载方式
- [ ] 知道 HF 与 vLLM 后端怎么切换及 API 启动思路

**实操过关（以后）：**

- [ ] chat / webchat 能加载 adapter 对话
- [ ] （可选）API 能用 OpenAI client 打通

## 常见坑

- 微调时用的 `template` 与推理不一致。
- adapter 与基座不是同一架构/同一微调实验。
- vLLM 未安装或版本不兼容却强行指定。
- API 的 `model` 字段与服务端期望不一致。
