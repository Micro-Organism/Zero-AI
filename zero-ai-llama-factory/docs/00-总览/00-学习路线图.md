# 00 · 学习路线图

## 本章目标

搞清楚：学什么、按什么顺序学、每章学完算过关的标准是什么。

> **本模块默认学习模式：纸面/概念学习**（无本机大空间、无显卡也可完整学完）。  
> 真正训练放到「将来有云端 GPU 时」再做；见 [13-无GPU与云端学习规划.md](../03-概念与工具/13-无GPU与云端学习规划.md)。

## 两条过关标准

| 模式 | 你现在用这个 | 过关长什么样 |
|------|--------------|--------------|
| **A. 概念过关（推荐当前）** | 能讲清流程、会读 YAML/数据格式、能做自测题 | 不要求本机 `pip install` / 训练 |
| **B. 实操过关（以后）** | 云端或有 GPU 机器上跑通闭环 | WebUI/CLI 训完 → 合并 → 推理 → 评估 |

下文表格里的「过关」默认按 **A**；括号内是 B 的加分项。

## 建议学习顺序

```text
认识框架 →（通读）安装与环境概念 → 数据格式
        → WebUI 四页职责 → YAML/SFT 参数 → 合并导出概念
        → 推理与评估概念 → 术语表 + 自测
        →（可选）算法/加速/分布式/RLHF
        →（有算力时）按云端规划实操
```

| 阶段 | 章节 | 概念过关（A） | 实操过关（B，以后） |
|------|------|--------------|---------------------|
| 入门 | 01～02 | 能说明框架能力；知道安装依赖分层 | `llamafactory-cli version` 成功 |
| 数据 | 03 | 能手写 Alpaca 样例 + 注册片段 | 注册进真实仓库并被训练读到 |
| 界面/配置 | 04～05 | 能默写 WebUI 四页；能精读一份 SFT YAML | WebUI 或 CLI 跑通 demo SFT |
| 主流程 | 06～08 | 能画出 保存→合并→推理→评估 | 云端跑通闭环 |
| 工具章 | 13～20、24～25 | 云端规划、术语、YAML、显存、自测、诊断、选型、Trainer 对比、解码 | 按规划租卡实操 |
| 进阶 | 09～12、21～23 | 算法/分布式地图；DeepSpeed / 多模态 / NPU 专章 | 按项目需要再开 |

## 前置知识（够用即可）

- 会读 Markdown / 会改 JSON、YAML 文本即可
- 知道 GPU / CUDA / 显存是「算力与显存」资源（不必本机有）
- 了解「基座模型 + 微调」的直觉（不必先啃 Transformer 公式）

## 推荐节奏（概念学习版）

1. **第 1 次**：01 + **13（无 GPU 规划）** + 14 术语表  
2. **第 2 次**：03 数据 + 16 YAML 精读（手写样例 / 注释配置）  
3. **第 3 次**：04 WebUI + 05 SFT + 06 合并（串主流程）  
4. **第 4 次**：07 推理 + 08 评估 + 17 显存估算  
5. **第 5 次**：15 源码导读 + **19 效果诊断** + **20 模型与 template** + 18 自测  
6. **第 6 次（扩展）**：**24 Trainer 对比** + **25 解码参数**；按需 21 DeepSpeed / 22 多模态 / 23 NPU  
7. **有算力以后**：回到 13 的实操清单，按 B 标准补闭环  
8. **按需**：09～12；持续补充 [推荐阅读.md](推荐阅读.md)

## 本模块与官方文档的关系

- 官方文档是权威来源：[中文](https://llamafactory.readthedocs.io/zh-cn/latest/) / [英文](https://llamafactory.readthedocs.io/en/latest/)
- 本目录是 **自学笔记 + 概念清单**，不是官网全文翻译
- 版本会变：示例里的模型名、YAML 路径以官方当前仓库为准

## 空间与仓库约定

- **不必**为本学习在笔记本上 clone 完整 LLaMA-Factory + 下载模型
- 读官方网页 / GitHub 网页版文件即可；需要时再在云端磁盘操作
- 不要把模型权重、`saves/`、大数据集提交进本学习仓库
- 密钥、Token 用环境变量，不要写进 md
