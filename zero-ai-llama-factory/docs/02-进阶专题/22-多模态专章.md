# 22 · 多模态专章

## 本章目标

在纯文本 SFT 主线之外，弄清 LLaMA-Factory 多模态（图像 / 视频 / 音频）数据怎么组织、`dataset_info` 怎么注册、训练与推理时还要注意什么。

> 官方数据处理：https://llamafactory.readthedocs.io/zh-cn/latest/getting_started/data_preparation.html  
> 模型支持 / 多模态构建：https://llamafactory.readthedocs.io/zh-cn/latest/advanced/model_support.html

## 何时才需要读本章

| 你的任务 | 建议 |
|----------|------|
| 纯文本客服 / 知识问答 | 可跳过；主线 03～08 足够 |
| 看图回答、截图理解、文档 VQA | 需要：图像列 + VL 模型 + VL template |
| 视频问答 | 需要：`videos` 列 |
| 语音相关 | 需要：`audios` 列 |

概念期建议：**先把文本 LoRA SFT 闭环搞懂**，再碰多模态（样本路径、占位符数量、显存都更麻烦）。

## 核心规则（务必记住）

1. 选 **多模态基座**（如 LLaVA、Qwen-VL 等），不要用纯文本模型硬训图像。
2. 使用对应的 **`template`（常含 `_vl` 等后缀）**。
3. 数据里媒体字段的 **文件数量**，必须与文本中的 **媒体占位标记数量严格一致**（官方硬性要求；具体标记写法以当前文档/样例为准）。
4. 路径要真实存在（相对仓库或绝对路径，按你运行时工作目录理解）。

## Alpaca 风格：图像

```json
[
  {
    "instruction": "描述这张图片的主要内容。",
    "input": "",
    "output": "图中是一只在草地上的猫。",
    "images": ["path/to/image.jpg"]
  }
]
```

`dataset_info.json` 注册示意：

```json
"my_mllm_zh": {
  "file_name": "my_mllm_zh.json",
  "columns": {
    "prompt": "instruction",
    "query": "input",
    "response": "output",
    "images": "images"
  }
}
```

## 视频 / 音频

结构类似，字段分别为 `videos`、`audios`（官方音频示例字段名为 `audios`；文档个别处笔误写成 audio 时，以 `columns` 与样例文件为准）。

```json
"videos": ["path/to/video.mp4"]
```

```json
"audios": ["path/to/audio.wav"]
```

注册时在 `columns` 里增加对应映射。

## ShareGPT 与官方样例

- ShareGPT 也可承载多模态（与 Alpaca 思路类似），官方有 `mllm` 类 demo。
- 建议网页打开：`data/mllm_demo.json`（若仓库中存在）及 `dataset_info.json` 中对应条目，对照字段。

## 训练与推理要点

| 环节 | 注意 |
|------|------|
| 模型 | VL / 多模态 Instruct 权重，体积通常更大 |
| template | 必须用多模态模板，不能套纯文本 template |
| cutoff_len | 图像/视频会额外吃资源，长度与分辨率都要保守 |
| 推理 | 官方有 `webchat` + VL 示例 YAML（如 qwen3vl 一类） |
| 磁盘 | 媒体文件本身可能远大于 json；概念期只读样例即可 |

## 与纯文本主线的对照

```text
文本：instruction/input/output (+ history)
多模态：同上 + images/videos/audios
         + VL 模型 + VL template + 占位符数量一致
```

## 检查点

- [ ] 能说出多模态相对文本多出来的三个要素：媒体列、VL 模型、VL template
- [ ] 知道「媒体数量 = 文本占位数量」
- [ ] 知道概念期应先文本后多模态

## 常见坑

- 用纯文本模型训带 `images` 的数据
- 路径写错或相对路径与启动目录不一致
- 一张图但文本里占位符数量对不上
- 一上来高分辨率长视频，显存直接爆
