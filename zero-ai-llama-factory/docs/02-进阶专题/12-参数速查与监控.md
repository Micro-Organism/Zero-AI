# 12 · 参数速查与监控（查阅）

## 本章目标

把「参数去哪查」和「训练过程怎么盯」固定成习惯；本页是索引，不是官方参数全书。

## 一、参数去哪查

权威页（随时打开）：

https://llamafactory.readthedocs.io/zh-cn/latest/advanced/arguments.html

建议按块记忆，而不是背每一个字段：

| 参数块 | 你常改什么 |
|--------|------------|
| 模型参数 | `model_name_or_path`、量化、导出、vLLM 相关 |
| 数据参数 | `dataset`、`template`、`cutoff_len`、`max_samples` |
| 微调参数 | `finetuning_type`、LoRA rank/target、Freeze、RLHF 相关 |
| 训练参数 | batch、累积、lr、epoch、scheduler、bf16、save/eval strategy |
| 生成/评估参数 | 解码与 eval task 相关 |
| 环境变量 | 设备可见性、API 端口等 |

命令行覆盖 YAML 的方式（第 05 章）：

```bash
llamafactory-cli train your.yaml learning_rate=5e-5 num_train_epochs=2
```

## 二、实验监控

官方 Monitors 常见选择：

| 工具 | 直觉 |
|------|------|
| LlamaBoard | 与 LLaMA-Factory 生态贴近的看板向能力 |
| TensorBoard | 本地看标量曲线，经典 |
| Wandb | 云端跟踪、对比实验方便 |
| MLflow | 偏工程化实验管理 |
| SwanLab | 开源跟踪，官方有专节与依赖 |

YAML 里常与 `report_to`、各工具自己的 token/项目名配置有关；以当前文档「实验监控」「SwanLab 参数」为准。

### Step by step（最小监控）

1. 基线：`plot_loss: true`，先看本地 loss 图。
2. 需要多实验对比时，再接 TensorBoard 或 SwanLab/Wandb。
3. 每次实验记录：git commit / YAML 路径 / `output_dir` / 关键超参 / 一两句结论。

## 检查点

- [ ] 遇到生僻参数会打开 Arguments 页，而不是盲目抄博客
- [ ] 至少会用一种方式看 loss / 指标
- [ ] 实验目录与配置可追溯

## 常见坑

- 博客里的旧参数名与当前版本不一致。
- 监控 token 写进仓库。
- 只盯训练 loss，不抽查生成质量。
