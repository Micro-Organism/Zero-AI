# 14 · 术语表

> 查阅用。按字母 / 拼音混排；后续遇到新词只追加，不删旧条。

## A–D

| 术语 | 白话 |
|------|------|
| Adapter | 适配器权重；LoRA 训出来的「补丁」，体积通常远小于全量模型 |
| Alpaca 格式 | 常见指令数据格式：`instruction` / `input` / `output` 等 |
| AWQ / GPTQ / AQLM | 一类训练后量化（PTQ）方法，用于压缩部署 |
| bf16 / fp16 | 混合精度训练常用数据类型，省显存、加速 |
| Checkpoint | 训练中途保存点，可用于续训或挑中间结果 |
| cutoff_len | 样本截断最大长度（token 级），越大越吃显存 |
| dataset_info.json | 数据集注册表；自定义数据必须登记 |
| DeepSpeed | 分布式/显存优化库，常见 ZeRO 分片 |
| DPO | 用 chosen/rejected 偏好对直接对齐的方法，少走部分 RL |
| DoRA 等 | LoRA 变体算法家族成员 |

## E–L

| 术语 | 白话 |
|------|------|
| epoch | 把训练数据完整过一遍称为 1 个 epoch |
| Export / Merge | 导出；常指把 LoRA 合并进基座得到完整模型 |
| finetuning_type | `lora` / `freeze` / `full` 等微调方式 |
| FlashAttention | 高效注意力实现，常能加速并省显存 |
| Freeze | 冻结大部分参数，只训部分层 |
| Full fine-tuning | 全参数微调 |
| gradient_accumulation_steps | 梯度累积步数；用时间换更大有效 batch |
| Hugging Face / Transformers | 常用模型加载与训练生态；LF 默认推理后端之一 |
| Instruct 模型 | 已经过指令微调、更适合对话的基座变体 |
| KTO | 用好坏标签（而非成对偏好）做对齐的方法 |
| LoRA | Low-Rank Adaptation，低秩适配微调 |
| LlamaBoard | 与 LLaMA-Factory 相关的实验看板能力 |

## M–R

| 术语 | 白话 |
|------|------|
| MMLU / C-Eval / CMMLU | 常见通用能力评测集 |
| NLG 评估 | 用 BLEU/ROUGE 等看生成与参考的重合度 |
| ORPO | 另一类偏好对齐算法 |
| output_dir | 训练输出根目录 |
| per_device_train_batch_size | 单卡每步样本数 |
| PPO | 经典 RLHF 中常用的强化学习算法之一 |
| PT / Pretrain | 预训练或增量预训练阶段 |
| PTQ | Post-Training Quantization，训练后再量化 |
| QAT | Quantization-Aware Training，训练中感知量化 |
| QLoRA | 在量化基座上做 LoRA，显著降显存 |
| ranking | 偏好数据集在注册信息里常需 `ranking: true` |
| resume_from_checkpoint | 从指定 checkpoint 续训 |
| RLHF | 借人类反馈做强化学习对齐的一类方法统称 |
| RM | Reward Model，奖励模型 |

## S–Z

| 术语 | 白话 |
|------|------|
| save_only_model | 主要存权重；常导致无法完整 resume |
| SFT | Supervised Fine-Tuning，监督微调 |
| ShareGPT 格式 | 以 `conversations` 等多角色消息组织的数据格式 |
| stage | 训练阶段：`sft` / `pt` / `dpo` / `kto` … |
| template | 对话模板，必须与模型族匹配 |
| Unsloth | 可选训练加速方案之一 |
| vLLM | 高吞吐推理引擎，可作 `infer_backend` |
| WebUI | 浏览器零代码界面：训练/评估/对话/导出 |
| ZeRO | DeepSpeed 中按阶段切分优化状态以省显存的技术 |

## LLaMA-Factory 命令速记

| 命令 | 用途 |
|------|------|
| `llamafactory-cli version` | 校验安装 |
| `llamafactory-cli webui` | 开 WebUI |
| `llamafactory-cli train *.yaml` | 训练 / 部分预测评估 |
| `llamafactory-cli export *.yaml` | 合并/导出 |
| `llamafactory-cli chat *.yaml` | 命令行对话 |
| `llamafactory-cli webchat *.yaml` | 网页对话 |
| `llamafactory-cli api *.yaml` | OpenAI 兼容 API |
| `llamafactory-cli eval *.yaml` | 通用能力评估 |
