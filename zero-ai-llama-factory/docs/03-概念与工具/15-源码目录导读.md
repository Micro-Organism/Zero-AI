# 15 · 源码目录导读

## 本章目标

不 clone 到本机，也能在脑中建立 LLaMA-Factory 上游仓库的「地图」：关键目录干什么、学习时优先点开哪些路径。

> 以 GitHub 仓库 [hiyouga/LLaMA-Factory](https://github.com/hiyouga/LLaMA-Factory) 为准；目录名随版本可能微调，但职责大体稳定。

## 建议在网页上优先打开的路径

| 路径 | 学什么 | 搭配章节 |
|------|--------|----------|
| `README.md` | 最新特性、安装摘要、支持模型列表 | 01、02 |
| `data/dataset_info.json` | 数据集如何注册 | 03 |
| `data/*demo*.json` | 数据格式样例 | 03 |
| `examples/train_lora/` | SFT LoRA YAML | 05、16 |
| `examples/merge_lora/` | 合并与量化导出 | 06 |
| `examples/inference/` | chat / api 配置 | 07 |
| `examples/extras/` | NLG eval 等扩展示例 | 08 |
| `src/llamafactory/`（或同等包路径） | 框架实现入口（进阶） | 12+ |

官方文档站点是「说明书」；`examples/` 是「可抄的作业纸」。

## 目录职责（概念图）

```text
LLaMA-Factory/
├── data/                 # 数据文件 + dataset_info 注册表
├── examples/             # 官方 YAML / 脚本示例（学习主战场）
├── src/…                 # Python 包实现（webui、train、chat…）
├── scripts/              # 辅助脚本（如 vllm_infer.py）
├── evaluation/           # 评估相关资源（若存在）
├── requirements/         # 可选依赖分册（metrics、深速等）
├── docker/               # 容器相关（若使用）
└── README / docs 链接    # 指向 readthedocs
```

## 数据流（读代码前先懂这个）

```text
dataset_info.json ──► 解析数据集
        │
YAML/WebUI 配置 ──► 选择 model / template / stage / 超参
        │
   Trainer 循环 ──► 写入 output_dir（adapter / ckpt / log）
        │
  export/chat/eval ──► 消费 output_dir 或 merged 模型
```

## 学习时怎么「逛」仓库（零下载）

1. 打开 GitHub 网页 → `examples/train_lora/` → 点开任意 `*_lora_sft.yaml`。
2. 对照 [16-YAML配置精读.md](16-YAML配置精读.md) 给自己讲一遍每个键。
3. 打开 `data/alpaca_zh_demo.json` 看几条真实样本。
4. 打开 `dataset_info.json` 搜这个 demo 的注册项，看 `columns` 映射。
5. 再打开 `examples/inference/` 对比「训练配置」和「推理配置」差哪些字段。

## 检查点

- [ ] 能说出 `data/`、`examples/`、源码包、`scripts/` 各自职责
- [ ] 知道学配置应优先看 `examples/`，而不是一上来深挖全部源码
- [ ] 能描述从数据注册到 `output_dir` 的数据流

## 常见坑

- 把博客里过时的目录结构当成当前仓库结构。
- 本机 clone `--depth 1` 后又把模型缓存进同一盘，空间爆掉（概念期直接避免）。
