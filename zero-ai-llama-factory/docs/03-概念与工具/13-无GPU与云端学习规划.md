# 13 · 无 GPU 与云端学习规划

## 本章目标

在本机没有显卡、磁盘紧张的前提下，规划「现在学什么 / 以后在哪练 / 练之前准备什么」，避免一上来 clone 源码+下模型把磁盘撑爆。

## 现在 vs 以后

| 阶段 | 做什么 | 不做什么 |
|------|--------|----------|
| **现在（概念期）** | 读 01～12、14～18；在纸上/笔记里写样例 JSON、YAML；做自测 | 本机装 CUDA、下 7B+ 权重、本地长时间训练 |
| **以后（实操期）** | 租云端 GPU 或用免费额度，按最小闭环跑 demo | 在本机硬盘堆多个全量模型副本 |

## 为什么本机不适合硬上

- 全量基座模型常见 **数 GB～数十 GB**；训练产物、缓存、依赖环境再占一截
- 无 GPU 时即使用 CPU 训练，慢到失去学习反馈
- 概念阶段用 **官方网页文档 + GitHub 在线看 examples** 性价比更高

## 将来算力选项（规划用，不绑定某一家）

按「有免费额度 / 按量付费 / 按卡时租用」自己选型即可：

| 类型 | 典型形态 | 适合 |
|------|----------|------|
| 笔记本免费 GPU 额度 | Colab / Kaggle Notebook 等 | 第一次跑通 demo、短实验 |
| 按量云主机 | 各家 GPU 云、AutoDL 类 | 稳定复现、要持久盘 |
| 公司/学校集群 | 内部 GPU 队列 | 正式实验 |
| NPU 等 | 昇腾等（见官方 multibackend） | 特定硬件环境 |

选型时优先问自己：

1. 磁盘是否够放下 **一个** 小 Instruct 模型 + LLaMA-Factory 环境？
2. 显存大概多少？（对照 [17-显存与规模估算.md](17-显存与规模估算.md)）
3. 数据是否允许上传到该平台？

## 最小实操闭环（留给有算力那天）

严格按这个顺序，避免一上来就上大模型：

```text
1. 云端新建干净环境
2. 按官方文档安装 LLaMA-Factory（只用云盘）
3. 用仓库自带 demo 数据 + 较小 Instruct 模型
4. LoRA SFT（先 1 个 epoch / 限制 max_samples）
5. chat 抽查 →（可选）merge →（可选）eval
6. 实验结束：下载有用的 adapter/日志，删掉大权重释放云盘
```

对应章节：02→03→04 或 05→07→08；记录用 [实验记录模板.md](../00-总览/实验记录模板.md)。效果不好时查 [19-训练效果诊断.md](19-训练效果诊断.md)。

## 模型从哪来（规划时就要想）

| 渠道 | 说明 |
|------|------|
| Hugging Face Hub | 国际常用；`model_name_or_path` 直接写仓库 id |
| 本地路径 | 先下载到云盘目录，再填绝对/相对路径 |
| ModelScope（魔搭） | 国内常更顺；官方 Extra 含 `modelscope` 相关依赖，用法以当前 README/文档为准 |

概念期不必选边；实操前确认：**网络能否下、许可证能否用、磁盘能否放下一个小 Instruct 模型**。

## 本机仍可做的「零权重」练习

不占模型空间，但能练真本事：

1. **手写 5～20 条** Alpaca JSON（记事本即可）
2. **手写** `dataset_info.json` 里的一条注册
3. **对照** [16-YAML配置精读.md](16-YAML配置精读.md) 给一份 YAML「逐项注释」
4. **估算**：假设只有 16GB / 24GB 显存，选模型与是否 QLoRA（第 17、20 章）
5. **做完** [18-自我检测题.md](18-自我检测题.md)
6. **对照** [19-训练效果诊断.md](19-训练效果诊断.md) 走一遍「假想故障」归因
