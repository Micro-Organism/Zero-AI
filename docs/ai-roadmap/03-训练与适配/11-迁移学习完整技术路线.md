# 迁移学习完整技术路线

> 一句话定位：复用源任务或大规模预训练得到的表示，通过特征提取、冻结、部分解冻或全量微调适配目标任务，并控制域偏移与灾难性遗忘。

## 快速概览

| 迁移方式 | 训练哪些参数 | 数据/成本 | 适合起点 |
|---|---|---|---|
| Feature Extraction | 不更新 backbone，仅离线提取特征 | 最低 | 极小数据、快速基线、检索 |
| Frozen Backbone + Head | 只训练任务头 | 低 | 源域与目标域相近、小数据 |
| Partial Unfreezing | 训练任务头与高层/指定模块 | 中 | 有一定域差，需要更强适应 |
| Full Fine-tuning | 更新全模型 | 高 | 数据较多、域差明显、资源足够 |
| Domain Continued Pre-training | 用目标域无标注数据延续自监督目标 | 高 | 领域语言/视觉分布系统性变化 |

## 学习地图（表格）

| Step | 主题 | 关键问题 | 必做实验 |
|---:|---|---|---|
| 1 | Source/Target 定义 | 迁移了什么表示，任务和域差在哪里 | 写迁移假设表 |
| 2 | 数据与基线 | split、类别、样本量、非迁移基线 | scratch baseline |
| 3 | Feature/Probe | 预训练表示是否已经可分 | linear probe |
| 4 | Frozen Head | 任务头能解决多少 | frozen backbone |
| 5 | Partial Unfreeze | 哪些层适应目标域 | 分层 LR 对比 |
| 6 | Full FT/PEFT | 适应能力与遗忘如何平衡 | full 或 LoRA 对比 |
| 7 | Domain Adaptation | 无标注/少标注目标域如何利用 | continued pre-training 或 adaptation |
| 8 | 评测与发布 | 目标域提升是否牺牲源域能力 | 双域回归报告 |

## 核心技术要点与扩展谱系

| 层级 | 技术要点 | 解决的问题 | 前置知识 | 掌握标准 | 关联章节 |
|---|---|---|---|---|---|
| 必会 | source/target task/domain、domain shift | 定义迁移发生在哪里 | ML、数据分布 | 能写四象限迁移假设 | `03` |
| 必会 | feature extraction、linear probe | 测试预训练表示可用性 | 预训练模型 | 能固定 backbone 建公平基线 | `07`、`09` |
| 必会 | frozen head、partial/staged unfreeze、discriminative LR | 控制适配深度与过拟合 | PyTorch、优化 | 能做三档消融 | `05` |
| 必会 | full FT、PEFT/adapter | 适应大域差或大模型 | 微调 | 能按数据/资源选更新范围 | `10` |
| 进阶 | domain continued pretraining、domain adversarial adaptation | 利用无标注目标域 | 预训练、对抗学习 | 能检查通用能力退化 | `09` |
| 进阶 | multi-task/meta/few-shot transfer | 跨任务共享与快速适配 | ML/DL | 能说明任务采样与负迁移 | `03-04` |
| 进阶 | replay、regularization/EWC、adapter isolation | 缓解灾难性遗忘 | 优化、旧任务数据 | 能同时报告源/目标回归 | `14` |
| 了解 | distillation、teacher-student、pseudo-label | 转移软知识或扩展标签 | 概率、半监督 | 能解释 temperature 与 confirmation bias | `16` |

## 预训练、微调与迁移学习总对比

| 概念 | 起始权重 | 数据规模 | 训练目标 | 计算成本 | 输出产物 | 典型用途 |
|---|---|---|---|---|---|---|
| 从零预训练 | 随机初始化 | 最大，通常通用宽覆盖 | 自监督语言/视觉建模 | 最高 | 基础模型权重 + tokenizer | 建立全新基础模型或研究架构 |
| 继续预训练 | 已有基础模型 | 中到大，通常领域语料 | 延续自监督目标 | 高 | 领域适配后的基础模型 | 补充领域语言、知识和分布 |
| 监督微调/对齐 | 已有基础或指令模型 | 小到中，高质量任务/偏好数据 | 指令响应、任务损失或偏好目标 | 中到低 | 全量权重或 Adapter | 改变任务行为、格式、风格和偏好 |
| 迁移学习 | 任意预训练模型 | 通常小到中 | 下游任务目标 | 低到中 | 特征、任务头或适配后模型 | 将已有表示迁移到新任务/领域 |

## 纵向：从原理到交付的完整闭环

```text
定义源域/源任务与目标域/目标任务 -> 测量域差与数据质量
 -> scratch/zero-shot 基线 -> feature extraction/linear probe
 -> frozen head -> partial unfreeze/PEFT -> full fine-tune（如必要）
 -> 目标域指标 + 源域/通用能力回归 -> 误差分析
 -> 导出/部署 -> 漂移监测 -> 重训或回滚
```

| 环节 | 应回答的问题 | 证据 |
|---|---|---|
| 迁移假设 | 源模型学到的哪些表示可复用 | source/target task-domain 对照 |
| 数据切分 | 同主体、时间、设备或模板是否跨集合 | split 规则与重复检查 |
| 基线 | 不迁移、零样本或固定特征表现如何 | scratch/zero-shot/probe 结果 |
| 适配深度 | 冻结多少层、不同层 LR 如何设 | 受控消融实验 |
| 遗忘检查 | 源域/通用能力是否退化 | 双域或多能力回归矩阵 |
| 交付监控 | 目标域分布变化怎样被发现 | slice、漂移指标、重训阈值 |

### LLM 迁移示例

| 目标 | 起点 | 迁移方法 | 应保留的回归 |
|---|---|---|---|
| 文本分类 | 预训练 Encoder | frozen embedding -> head -> full FT | 通用语义切片、多语言 |
| 领域问答行为 | Instruct LLM | LoRA/QLoRA SFT | 通用问答、安全、格式 |
| 领域语言分布 | Base LLM | continued pre-training -> SFT | 通用语言与知识能力 |
| 语义检索 | Embedding model | hard negatives + contrastive FT | 通用检索和跨域 query |

### CV 迁移示例

| 目标 | 起点 | 迁移方法 | 应保留的回归 |
|---|---|---|---|
| 小样本分类 | ImageNet backbone | frozen head -> partial unfreeze | 源风格与不同光照 |
| 工业缺陷检测 | detection backbone | neck/head 训练 -> backbone 解冻 | 小目标、不同设备 |
| 医学分割 | 通用/医学 backbone | decoder/head -> staged unfreeze | 不同机构/设备切片 |
| 图文检索 | CLIP | projection/PEFT/contrastive FT | 通用图文匹配、长尾概念 |

## 横向：与其他技术的连接

- **与预训练**：预训练创建可迁移表示；基础模型越贴近目标域，后续所需标注和更新通常越少。
- **与微调**：微调是实现迁移学习的主要手段之一；迁移学习描述问题范式，LoRA/全量微调描述参数更新方式。
- **与领域适配**：source/target 任务可相同但数据分布不同；继续预训练、对抗适配或伪标签都可能用于缩小域差。
- **与 NLP/CV**：BERT 加分类头、ImageNet backbone 加任务头是同一迁移思想在不同模态的实现。
- **与评测**：只看目标域平均指标会掩盖负迁移、遗忘和群体/场景退化，必须保留源域或通用回归集。
- **与 MLOps**：基础模型、Adapter、任务头、数据与推理预处理必须共同版本化，否则无法复现迁移链路。

## 技术对比与选型

### 更新深度对比

| 策略 | 优点 | 风险 | 选择信号 |
|---|---|---|---|
| Fixed Features | 快、稳定、可缓存 | 表示无法适应目标域 | 极小数据、需要快速基线 |
| Frozen + Head | 参数少、过拟合风险低 | 域差大时上限低 | 目标标签新、底层特征通用 |
| Partial Unfreeze | 成本与适应能力平衡 | 解冻边界和 LR 需实验 | 中等域差、数据有限 |
| PEFT | 对大模型存储/训练友好 | target module 选择影响结果 | LLM/VLM 多任务 Adapter |
| Full Fine-tuning | 最大适应自由度 | 显存高、易遗忘/过拟合 | 数据和算力充分、域差大 |

### 常见适配问题对比

| 类型 | 什么发生变化 | 例子 | 优先方法 |
|---|---|---|---|
| Task Transfer | 任务变、域相近 | 通用 BERT -> 新闻分类 | head/partial/full FT |
| Domain Adaptation | 任务近似、数据分布变 | 通用图像 -> 医学图像 | continued pre-training + staged FT |
| Cross-lingual Transfer | 语言分布变 | 多语模型 -> 低资源语言 NER | multilingual FT、adapter |
| Multi-task Transfer | 多任务共享表示 | 分类 + NER + QA | shared backbone + task heads/instruction |
| Negative Transfer | 源知识妨碍目标任务 | 不匹配领域导致指标下降 | 更换底座、少解冻、重配数据 |

### 灾难性遗忘缓解方法

| 方法 | 思路 | 代价/限制 |
|---|---|---|
| 小学习率/分层 LR | 越靠近通用底层更新越小 | 需要调参，不能解决所有域冲突 |
| 渐进解冻 | 先任务头再逐层开放 | 训练阶段更多 |
| 数据混合/Replay | 加入源域或通用样本 | 需要合法保留原数据，增加成本 |
| PEFT/Adapter | 限制更新子空间并保留底座 | Adapter 路由和管理变复杂 |
| 正则约束 | 限制新旧参数或表示偏移 | 目标适应能力可能受限 |

## Step by Step

1. 明确 source task/domain、target task/domain、可用标注和迁移假设，定义目标与不可退化指标。
2. 建立 scratch、zero-shot 或固定特征基线，确认预训练表示是否真的带来增益。
3. 训练 frozen backbone + task head，记录参数量、显存、速度和目标指标。
4. 分阶段解冻高层，使用分层学习率；一次只改变解冻范围或 LR。
5. 在数据与资源允许时比较 full fine-tuning；大模型先使用 LoRA/PEFT 基线。
6. 同时评测 target、source/general、长尾和关键安全 slice，识别负迁移与遗忘。
7. 若域差仍明显，尝试领域继续预训练或数据适配，然后重新做相同下游评测。
8. 固定 backbone、head/Adapter、预处理和标签映射版本，部署后监测目标域漂移。

## 最小项目与验收标准

**项目：NLP 或 CV 小样本迁移学习消融实验**

| 验收项 | 过关标准 |
|---|---|
| 假设 | 清楚定义 source/target 的任务与域差 |
| 数据 | split 防止主体/模板/时间泄漏，报告类别和 slice |
| 对比 | 至少包含 scratch/zero-shot、frozen、partial、full/PEFT 四档中的三档 |
| 公平性 | 使用相同 split、预处理、指标与合理训练预算 |
| 遗忘 | 同时报告目标域与源域/通用回归结果 |
| 工程 | 模型、预处理、任务头/Adapter 和标签版本可追溯 |
| 结论 | 能基于数据量、域差、资源解释最佳更新深度 |

## 常见误区与面试达标

- 误区：把迁移学习和微调当成两个互斥项目；前者是范式，后者是常用手段。
- 误区：默认预训练模型一定更好，不建立 scratch/zero-shot/probe 基线来检查负迁移。
- 误区：一开始全量解冻，却没有 frozen/partial 对照，也没有通用能力回归。
- 面试达标：能用 source/target task 与 domain 四个概念描述迁移问题。
- 面试达标：能解释 feature extraction、linear probe、partial unfreeze、PEFT、full FT 的成本与适用条件。
