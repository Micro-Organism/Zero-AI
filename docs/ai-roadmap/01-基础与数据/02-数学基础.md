# AI 工程师数学基础路线

> 一句话定位：数学的目标是解释模型表示、损失、梯度、不确定性和评测，而不是脱离代码背公式。

## 快速概览

| 数学分支 | AI 中的作用 | 最小掌握证据 |
|---|---|---|
| 线性代数 | Embedding、线性层、Attention、降维 | 能追踪 shape，解释点积、范数和投影 |
| 微积分 | 反向传播、梯度、优化 | 能用链式法则手算两层简单网络 |
| 概率 | 分布、生成、似然、不确定性 | 能解释 softmax、交叉熵与最大似然 |
| 统计 | 抽样、估计、A/B、置信区间 | 能区分波动与真实提升 |
| 优化 | SGD/Adam、学习率、正则化 | 能根据 loss/梯度现象调整实验 |

## 纵向：从原理到交付的完整闭环

```text
数据表示(线代) -> 模型函数 -> 损失(概率/信息论)
                  -> 梯度(微积分) -> 参数更新(优化)
                  -> 指标与置信度(统计) -> 决策
```

| 模型环节 | 数学问题 | 工程问题 |
|---|---|---|
| 输入 | 尺度、维度、相似度 | dtype/shape/归一化是否正确 |
| 损失 | 目标的概率含义 | 损失是否与业务指标一致 |
| 优化 | 梯度方向、局部曲率 | 学习率、梯度爆炸/消失 |
| 评测 | 估计偏差与方差 | 指标差异是否超过随机波动 |

## 横向：与其他技术的连接

- **Transformer**：QK 点积、缩放、softmax 和 V 加权是线代 + 概率的组合。
- **Embedding/RAG**：余弦、内积、L2 距离对应不同检索假设，应与索引配置一致。
- **CV**：卷积是共享权重的局部线性运算，图像增强涉及几何变换。
- **评测**：排名指标、bootstrap 置信区间和 A/B 阻止“一次分数就下结论”。
- **性能**：矩阵乘的计算/存储复杂度帮助判断显存和吞吐瓶颈。

## 技术对比与选型

| 概念 | 回答的问题 | 常见误用 |
|---|---|---|
| 交叉熵 | 模型给真实类别的概率有多大 | 与 accuracy 当成同一类指标 |
| KL 散度 | 一个分布相对另一个分布损失多少信息 | 当成对称距离 |
| 余弦相似度 | 方向是否接近 | 忽略模长本身包含信息的场景 |
| Pearson/Spearman | 线性关系/单调排名关系 | 有离群值时盲目使用 Pearson |
| SGD/Adam | 噪声梯度/自适应步长 | 只换优化器不调学习率与 schedule |

## Step by Step

1. 用 NumPy 跟踪线性层和二维 Attention 示例的每一个 shape。
2. 手写线性回归的 MSE 梯度，与有限差分及 PyTorch autograd 对比。
3. 从 softmax + 交叉熵推出“错误且自信”的惩罚为什么大。
4. 用模拟数据观察样本数对均值和置信区间的影响。
5. 用 bootstrap 比较两个模型指标，记录点估计和区间。
6. 在同一小网络上比较 SGD/Adam、两个学习率和两个 seed。

## 最小项目与验收标准

**项目：从零实现并分析逻辑回归**

| 验收项 | 过关标准 |
|---|---|
| 数学 | 能写出 sigmoid、交叉熵和梯度的含义 |
| 代码 | NumPy 实现与 scikit-learn 结果趋势一致 |
| 统计 | 报告不只有一个 accuracy，包含分类不平衡指标和置信区间 |
| 表达 | 能画出 loss 曲线，解释学习率过大/过小的现象 |

## 常见误区与面试达标

- 误区：能调库就认为不需要数学；出现 NaN、指标异常或检索错误时将无法定位。
- 误区：只背公式不能解释 tensor shape、单位和概率语义。
- 面试达标：能从 Q/K/V 的 shape 说到 attention score 和复杂度。
- 面试达标：能说明“模型 A 分数高 0.5%”为什么不一定有统计或业务意义。
