# 机器学习路线

> 一句话定位：学会将业务问题转换为可验证的学习任务，用正确数据分割、基线和指标得到可信结论。

## 快速概览

| 问题类型 | 例子 | 常见方法 | 首要指标 |
|---|---|---|---|
| 分类 | 垃圾文本、风险用户 | Logistic Regression、Tree/Boosting | F1、PR-AUC、召回率 |
| 回归 | 需求量、成本预估 | Linear/Ridge、Boosting | MAE、RMSE |
| 排序 | 检索、推荐 | Learning to Rank、相似度 | NDCG、MRR、Recall@K |
| 聚类/异常 | 用户分群、异常流量 | K-Means、Isolation Forest | 轮廓系数 + 业务复核 |

## 学习地图（表格）

| 阶段 | 知识 | 必做练习 |
|---|---|---|
| 问题定义 | 样本、特征、标签、损失、指标 | 把一个业务问题写成 ML 问题定义 |
| 数据 | EDA、缺失、异常、不平衡、泄漏 | 用时间/用户边界拆分数据 |
| 基线 | Dummy、线性模型、简单树 | 在复杂模型前记录可解释基线 |
| 建模 | 线性、树、集成、聚类 | Pipeline + 交叉验证 |
| 评测 | confusion matrix、ROC/PR、校准 | 按错误类型做 slice 分析 |
| 交付 | 版本、特征一致性、漂移 | 保存 pipeline 并用未见数据重放 |

## 核心技术要点与扩展谱系

| 层级 | 技术要点 | 解决的问题 | 前置知识 | 掌握标准 | 关联章节 |
|---|---|---|---|---|---|
| 必会 | Linear/Logistic Regression、正则化 | 回归分类基线与可解释关系 | 线代、概率 | 能推导 loss 并分析系数 | `02` |
| 必会 | Decision Tree、Random Forest、GBDT/XGBoost 类 | 非线性表格学习 | 特征/划分 | 能比较 bagging、boosting 和过拟合 | `22-23` |
| 必会 | kNN、Naive Bayes、SVM | 距离、概率和最大间隔范式 | 概率、向量 | 能按数据规模和边界选基线 | `06` |
| 必会 | k-means、DBSCAN、PCA | 聚类、异常结构和降维 | 距离、SVD | 能用可视化与指标解释结果 | `02` |
| 必会 | split、cross-validation、pipeline、feature leakage | 可信评测和预处理 | 数据工程 | 能构造无泄漏实验 | `14`、`19` |
| 进阶 | imbalance、calibration、threshold、cost-sensitive learning | 类别不平衡和业务决策 | 指标、概率 | 能从 PR 曲线选择阈值 | `14` |
| 进阶 | semi/self-supervised、active learning、anomaly detection | 标签不足与异常发现 | 表示学习 | 能说明数据假设和评测困难 | `04`、`07-08` |
| 了解 | causal inference、uplift、bandit | 从相关预测走向干预决策 | 统计实验 | 能区分预测、因果和在线探索 | `22` |

## 纵向：从原理到交付的完整闭环

```text
业务目标 -> 标签/样本定义 -> 无泄漏拆分 -> Dummy/简单基线
         -> Pipeline 训练 -> 交叉验证 -> 阈值/校准 -> 误差分析
         -> 模型导出 -> 线上特征一致 -> 漂移监测
```

| 风险 | 现象 | 防护 |
|---|---|---|
| 数据泄漏 | 离线过高，线上失效 | 按时间/主体拆分，预处理放 Pipeline |
| 过拟合 | train 好、validation 差 | 正则化、降复杂度、加数据 |
| 指标错位 | accuracy 高但关键类漏掉 | 根据代价选 precision/recall/PR-AUC |
| 分布漂移 | 上线后逐渐退化 | 监测输入、输出、标签延迟 |

## 横向：与其他技术的连接

- **深度学习**：数据分割、基线、指标和误差分析完全继承，只是模型和训练更复杂。
- **RAG**：检索是排序问题，需要 Recall@K/MRR/NDCG，不能只看最终回答。
- **LLM 评测**：模型评审仍需要对照、隔离测试集和人工校准。
- **MLOps**：特征/模型版本、数据漂移和回滚是传统 ML 与 LLM 共通能力。

## 技术对比与选型

| 方法 | 优势 | 限制 | 优先使用 |
|---|---|---|---|
| 线性/逻辑回归 | 快、稳定、可解释 | 非线性表达弱 | 基线、稀疏高维特征 |
| Random Forest | 对非线性和异常较稳健 | 模型大、外推弱 | 表格数据快速基线 |
| XGBoost/LightGBM | 表格数据常有强表现 | 调参和泄漏风险 | 有明确表格特征的业务 |
| 神经网络 | 端到端表示学习 | 数据/算力/调试成本高 | 文本、图像、语音和大数据 |

## Step by Step

1. 选一个表格数据集，先写业务目标、标签时点和泄漏清单。
2. 建 Dummy 和 Logistic/Linear 基线，再加树模型。
3. 用 Pipeline 封装缺失、编码、缩放和模型，保证训测一致。
4. 用交叉验证与隔离 test 分别做选型和最终报告。
5. 按类别/人群/时间切片分析失败，调整阈值而不只换模型。
6. 导出 pipeline，写一个批量预测 CLI 和数据漂移报告。

## 最小项目与验收标准

**项目：不平衡文本/表格分类基线**

| 验收项 | 过关标准 |
|---|---|
| 数据 | 说明拆分边界且无主体/时间泄漏 |
| 对比 | Dummy、线性、树模型至少三个基线 |
| 指标 | 包含 PR-AUC/F1/召回和 confusion matrix，说明阈值 |
| 结论 | 包含错误切片、限制和下一次实验 |

## 常见误区与面试达标

- 误区：在全数据 fit 缩放/特征选择后再交叉验证。
- 误区：类别不平衡只报 accuracy，不讲阈值和错误代价。
- 面试达标：能说明 bias-variance、正则化、交叉验证与 test 集的分工。
