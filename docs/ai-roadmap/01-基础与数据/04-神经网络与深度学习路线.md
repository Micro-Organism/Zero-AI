# 神经网络与深度学习路线

> 一句话定位：理解神经网络如何学习表示，并能通过曲线、梯度和数据现象诊断训练失败。

## 快速概览

| 组件 | 作用 | 常见失败 |
|---|---|---|
| 线性层 + 激活 | 组合非线性函数 | 没激活时多层仍等价线性 |
| 损失函数 | 把目标转成可优化标量 | 与任务/输出形状不匹配 |
| 反向传播 | 通过链式法则求梯度 | 梯度消失、爆炸、意外 detach |
| 优化器/schedule | 更新参数与调节步长 | lr 过大震荡、过小不学习 |
| 正则化 | 提高泛化 | 过强导致欠拟合 |

## 学习地图（表格）

| 阶段 | 必备知识 | 实验 |
|---:|---|---|
| 1 | perceptron、MLP、激活 | NumPy 前向传播 |
| 2 | loss、链式求导、backprop | 数值梯度 vs autograd |
| 3 | SGD/Momentum/Adam、lr schedule | 固定模型比较优化轨迹 |
| 4 | initialization、normalization、residual | 深度与梯度统计实验 |
| 5 | dropout、weight decay、augmentation | 过拟合对照 |
| 6 | CNN、RNN、Attention/Transformer | 同一任务的结构归纳 |

## 核心技术要点与扩展谱系

| 层级 | 技术要点 | 解决的问题 | 前置知识 | 掌握标准 | 关联章节 |
|---|---|---|---|---|---|
| 必会 | Perceptron、MLP、activation、universal approximation | 建模非线性映射 | 线代、梯度 | 能从零实现前后向并过拟合小样本 | `02`、`05` |
| 必会 | CNN：convolution、kernel、stride、padding、receptive field | 保留空间局部结构和参数共享 | 张量 shape | 能计算输出尺寸并训练图像分类器 | [07 CV](../02-模型与方向/07-CV技术路线.md) |
| 必会 | RNN、BPTT、vanishing/exploding gradient | 建模有序序列与历史状态 | 链式法则 | 能展开时间图并解释长依赖困难 | `06`、`23-24` |
| 必会 | LSTM、GRU、门控记忆 | 缓解普通 RNN 长依赖和梯度问题 | RNN | 能画门控、比较参数与最小实验 | `06`、`23` |
| 必会 | Attention、Self/Cross-Attention、Transformer | 并行建模全局依赖 | 矩阵/softmax | 能解释 Q/K/V、mask 和位置 | `08`、`13` |
| 必会 | loss、backprop、initialization、Norm、Dropout、Residual | 稳定深层网络训练 | 优化 | 能按曲线诊断欠拟合/过拟合/不稳定 | `05` |
| 进阶 | Autoencoder、VAE、GAN、Diffusion/Flow | 表示压缩与生成建模 | 概率、CNN | 能比较目标函数与采样机制 | `08`、`13` |
| 进阶 | GNN/GCN/GAT、message passing | 建模节点和关系结构 | 图、线代 | 能完成节点/图任务并解释聚合 | `17`、`22-23` |
| 进阶 | TCN、ConvLSTM、3D CNN、spatiotemporal Transformer | 联合时间与空间结构 | CNN/RNN | 能按数据形态选择时空模型 | [23 时序](../02-模型与方向/23-时序预测路线.md) |
| 了解 | self-supervised、contrastive、world model、Mixture-of-Experts | 扩展无标签表示和模型容量 | 深度学习主干 | 能定位其训练信号与工程代价 | `07-09`、`17` |

## 纵向：从原理到交付的完整闭环

```text
数据批次 -> forward -> loss -> zero_grad -> backward -> clip/check gradients
          -> optimizer.step -> scheduler.step -> validation -> checkpoint -> error analysis
```

| 观察 | 可能原因 | 优先检查 |
|---|---|---|
| loss 不降 | 数据/标签错、lr 小、梯度断 | 单批过拟合、grad norm、label 分布 |
| loss NaN | lr 大、溢出、非法数据 | 输入范围、混合精度、梯度裁剪 |
| train 好/val 差 | 过拟合或分布差 | 分割、数据重复、增强/正则 |
| train/val 都差 | 欠拟合、特征/标签弱 | 数据可学性、基线、模型容量 |

## 横向：与其他技术的连接

- **ML 纪律**：深度学习不免除数据泄漏、基线和独立 test 集。
- **NLP/CV**：数据映射不同，但 forward/loss/backward/eval 训练骨架相同。
- **LLM**：Transformer 是深度网络，残差、归一化、初始化与混合精度决定训练稳定。
- **性能工程**：batch、序列/图像尺寸、activation 是显存的核心来源。

## 技术对比与选型

| 对比 | 主要差异 | 选择原则 |
|---|---|---|
| ReLU/GELU/SiLU | 分段线性/平滑门控特性 | 跟随架构惯例，不为微小差异盲目换 |
| BatchNorm/LayerNorm | 按 batch 统计/按样本特征归一 | CNN 常见 BN；Transformer 优先 LN/RMSNorm |
| SGD/AdamW | 简单动量/自适应二阶矩估计 | CV 可比 SGD；Transformer 常用 AdamW |
| Dropout/weight decay | 随机丢活/约束权重 | 结合数据量和验证过拟合程度 |

## Step by Step

1. NumPy 实现两层 MLP forward，手工跟踪 shape。
2. 用有限差分检查简单参数梯度。
3. PyTorch 写训练循环，先验证能过拟合一个 mini-batch。
4. 记录 train/val loss、学习率、grad norm 和关键指标。
5. 做学习率、正则化、数据增强的单变量实验。
6. 从最佳 checkpoint 恢复并在 test 集只评一次。

## 最小项目与验收标准

**项目：MLP/CNN 训练与失败诊断**

| 验收项 | 过关标准 |
|---|---|
| 训练 | 手写循环，能单批过拟合，能恢复 checkpoint |
| 诊断 | 展示 lr 过大、过小和过拟合至少三种现象 |
| 消融 | 每次只改一个变量，记录运行配置与 seed |
| 报告 | 结论能由曲线、指标和错误案例支撑 |

## 常见误区与面试达标

- 误区：loss 不降就立即换大模型，不先过拟合单批和检查数据。
- 误区：把残差连接说成解决 RNN 长距离依赖的核心方法。
- 面试达标：能画出 forward/backward 数据流，区分参数、梯度、activation 和 optimizer state。
