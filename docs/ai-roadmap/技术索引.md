# AI 技术索引

> 用途：按技术名称反查主章节和关联知识。主章节负责详细解释，关联章节说明它的前置、组件或应用，避免同一技术在多处重复且内容漂移。

## 使用规则

| 层级 | 含义 | 学习要求 |
|---|---|---|
| 必会 | 该方向不可跳过的稳定基础 | 能解释原理、实现最小实验、分析错误 |
| 进阶 | 主流工程或专项深入技术 | 能与替代方案做公平对比和选型 |
| 了解 | 代表性前沿或特定场景技术 | 能定位问题、前置、成本和适用边界 |

新遇到一个技术时依次问：它解决什么问题；输入输出是什么；属于模型、训练方法、框架还是基础设施；主归属在哪里；用什么实验和指标验证。

## 如何补充新技术

1. 先在索引中搜索别名和缩写，避免重复建条目。
2. 按“解决的问题”确定唯一主章节，不按论文或框架热度归类。
3. 在主章节的技术谱系加入前置和掌握标准；关联章节只增加链接。
4. 至少指定一个替代方案、指标或最小实验。
5. 技术成熟度变化时调整层级，不删除仍有教学价值的经典方法。
