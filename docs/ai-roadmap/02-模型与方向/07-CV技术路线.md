# CV 技术路线

> 一句话定位：掌握图像分类、检测和分割的数据-训练-评测闭环，为多模态和机器人感知打基础。

## 快速概览

| 任务 | 输出 | 代表模型 | 核心指标 |
|---|---|---|---|
| 分类 | image label | ResNet、ViT | Accuracy、Macro-F1 |
| 检测 | box + label | YOLO、Faster R-CNN | mAP |
| 分割 | pixel mask | U-Net、DeepLab、SAM | IoU、Dice |
| 表示/图文 | embedding | CLIP | Recall@K、zero-shot accuracy |

## 学习地图（表格）

| Step | 主题 | 必做实验 |
|---:|---|---|
| 1 | 像素、通道、尺寸、归一化 | 可视化预处理前后 |
| 2 | 卷积、感受野、池化 | 跟踪 CNN feature map shape |
| 3 | augmentation、imbalance、split | 防止同主体图像泄漏 |
| 4 | transfer learning | frozen head -> partial -> full 对比 |
| 5 | detection/segmentation | 各跑一个小数据集 |
| 6 | ViT/CLIP | 图文 embedding 检索 |

## 核心技术要点与扩展谱系

| 层级 | 技术要点 | 解决的问题 | 前置知识 | 掌握标准 | 关联章节 |
|---|---|---|---|---|---|
| 必会 | image tensor、color space、resize/crop/normalize、augmentation | 正确构造视觉输入 | 张量、图像基础 | 能保证训练部署预处理一致 | `05`、`15` |
| 必会 | CNN、LeNet/AlexNet/VGG、ResNet、receptive field | 提取局部到层级视觉特征 | [04 CNN](../01-基础与数据/04-神经网络与深度学习路线.md) | 能跟踪 feature map 并解释 residual | `04-05` |
| 必会 | classification、transfer learning、class imbalance | 图像级预测 | CNN、ML 指标 | 能比较 scratch/frozen/full | `11`、`14` |
| 必会 | detection：R-CNN/Faster R-CNN、YOLO、anchor/anchor-free | 定位并分类目标 | CNN、box geometry | 能解释 IoU、NMS、mAP 与错误类型 | `14` |
| 必会 | segmentation：FCN/U-Net/DeepLab、semantic/instance/panoptic | 像素级理解 | CNN、upsampling | 能解释 IoU/Dice 与边界错误 | `13` |
| 进阶 | ViT、Swin、DETR | 用 Transformer 建模视觉和集合预测 | Attention | 能比较 CNN 归纳偏置与 ViT 数据需求 | `08`、`13` |
| 进阶 | self-supervised vision：SimCLR/MoCo/MAE/DINO 类 | 无标签视觉表示 | 对比/掩码学习 | 能做 linear probe 和迁移对比 | `09`、`11` |
| 进阶 | OCR、pose、depth、optical flow、3D/point cloud | 文档、人体、几何和运动理解 | CV 主干 | 能按输出空间选择指标 | `13`、`17` |
| 了解 | video model、3D CNN、ConvLSTM、NeRF/Gaussian Splatting | 时空与三维场景表示 | CNN/RNN/几何 | 能判断视频预测与三维重建差异 | [23 时序](./23-时序预测路线.md)、`17` |

## 纵向：从原理到交付的完整闭环

```text
标注规范 -> 数据按主体/场景拆分 -> augmentation -> pretrained backbone
         -> head/partial/full fine-tune -> task metric -> 按光照/角度/设备 slice
         -> export/serving -> 延迟/误报/漏报监测
```

| 环节 | 特有风险 | 检查 |
|---|---|---|
| 数据 | 连拍/同对象泄漏 | 按设备、时间、主体拆分 |
| 增强 | 改变标签语义 | 逐种可视化并验证 mask/box |
| 评测 | 平均指标掩盖长尾 | 按类别、尺寸、场景 slice |
| 部署 | 预处理与训练不一致 | 固定图像端到端回归 |

## 横向：与其他技术的连接

- **迁移学习**：ImageNet 预训练 backbone -> 下游任务是最直观的迁移学习实验。
- **多模态**：CLIP/VLM 在视觉 encoder 与文本模型之间建立对齐。
- **机器人**：检测、分割、深度/位姿估计是感知层，不等于规划和控制。
- **性能工程**：图像分辨率、batch、augmentation CPU 成本与模型结构共同决定吞吐。

## 技术对比与选型

| 对比 | 优势 | 适用 | 取舍 |
|---|---|---|---|
| CNN vs ViT | 局部偏置/全局 attention | 中小数据/大规模预训练 | ViT 更依赖数据与预训练 |
| YOLO vs Faster R-CNN | 单阶段快/两阶段精细 | 实时/精度导向 | 需在目标硬件测延迟 |
| U-Net vs SAM | 任务训练/通用提示分割 | 垂直领域/交互式标注 | SAM 不自动保证领域精度 |
| 冻结 vs 全量微调 | 低成本稳定/适应强 | 小数据/大域差 | 逐步解冻并验证 |

## Step by Step

1. 用小图像数据集建立类别/尺寸/主体统计。
2. 训一个小 CNN 基线，画出 train/val 曲线与 confusion matrix。
3. 用预训练 ResNet/ViT 比较 frozen head、partial unfreeze 和 full fine-tune。
4. 加入每种 augmentation 前先可视化，不改变标签语义。
5. 从分类扩展到检测或分割一项，学会对应指标。
6. 用 CLIP embedding 完成图文检索小实验。

## 最小项目与验收标准

**项目：小样本图像分类迁移学习**

| 验收项 | 过关标准 |
|---|---|
| 拆分 | 同主体/连拍不跨 train/test |
| 对比 | scratch、frozen、partial 至少三组 |
| 切片 | 按类别、光照、尺寸或设备分析 |
| 部署 | 导出后的预处理与 PyTorch 结果对齐 |

## 常见误区与面试达标

- 误区：随机拆分同一个物体的连拍图，造成数据泄漏。
- 误区：只看整体 accuracy，忽略罕见类和小目标。
- 面试达标：能解释卷积、感受野、迁移学习及 detection/segmentation 指标。
