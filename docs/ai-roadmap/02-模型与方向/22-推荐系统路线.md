# 推荐系统技术路线

> 一句话定位：用用户-物品-上下文反馈构建召回、粗排、精排和重排闭环，并处理曝光偏差、冷启动、多目标与反馈循环。

## 快速概览
| 层 | 目标 | 代表方法 | 指标 |
|---|---|---|---|
| 候选生成 | 从海量物品找候选 | 热门、协同、双塔、ANN | Recall@K |
| 排序 | 预测点击/转化/价值 | LR、GBDT、DeepFM、Transformer | AUC/NDCG |
| 重排 | 多样性与约束 | 规则、MMR、多目标优化 | diversity/coverage |
| 在线学习 | 适应反馈 | bandit、增量特征 | regret/业务指标 |

## 学习地图（表格）
| Step | 主题 | 必做实验 |
|---:|---|---|
| 1 | 反馈与数据 | impression/click/conversion 时间链 |
| 2 | 非个性化基线 | 热门、最近、规则 |
| 3 | 协同过滤 | user/item CF、matrix factorization |
| 4 | 召回 | two-tower、negative sampling、ANN |
| 5 | 排序 | 特征交叉、CTR/CVR、多任务 |
| 6 | 重排 | 多样性、新颖性、公平与业务约束 |
| 7 | 离线/在线评测 | temporal split、counterfactual 限制、A/B |
| 8 | 系统 | feature freshness、延迟、feedback loop |

## 核心技术要点与扩展谱系

| 层级 | 技术要点 | 解决的问题 | 前置知识 | 掌握标准 | 关联章节 |
|---|---|---|---|---|---|
| 必会 | popularity、user/item CF、implicit feedback | 建立非个性化与协同基线 | SQL、相似度 | 能解释曝光与负反馈假设 | `03`、`19` |
| 必会 | matrix factorization、BPR、negative sampling | 学习用户物品低秩表示 | 线代、ranking loss | 能比较 pointwise/pairwise 目标 | `02-03` |
| 必会 | FM/FFM、Wide&Deep、DeepFM | 建模稀疏特征交叉 | MLP、embedding | 能实现 CTR baseline 并校准 | `03-04` |
| 必会 | two-tower、ANN/HNSW/IVF | 大规模语义召回 | embedding、检索 | 能测 Recall@K、延迟和索引版本 | `12` |
| 必会 | ranking、multi-task CTR/CVR、reranking | 精排与多业务目标 | 分类/排序指标 | 能报告 NDCG、校准和约束 | `14` |
| 进阶 | DIN/DIEN、SASRec/BERT4Rec、sequence Transformer | 建模用户行为序列与兴趣 | RNN/Attention | 能处理时间、mask 和长短期兴趣 | `06`、`23` |
| 进阶 | graph recommendation、LightGCN/GNN | 利用高阶交互图结构 | GNN | 能解释 message passing 与采样 | `04` |
| 进阶 | bandit、exploration、counterfactual/IPS | 处理在线探索与曝光偏差 | 概率、因果 | 能设计 guardrail 与离线估计边界 | `14` |
| 了解 | LLM recommendation、generative retrieval | 使用语义和生成统一推荐 | LLM、召回排序 | 能识别延迟、幻觉和规模限制 | `08`、`12` |

## 纵向：从原理到交付的完整闭环
```text
业务目标 -> 曝光/反馈日志 -> 时间切分 -> 热门/规则 baseline
        -> 多路召回 -> 粗排/精排 -> 约束重排 -> 离线回放
        -> shadow/A-B -> 用户与生态指标 -> 偏差/漂移 -> 迭代
```
| 风险 | 表现 | 控制 |
|---|---|---|
| 曝光偏差 | 未曝光物品没有反馈 | 记录 propensity、谨慎解释离线数据 |
| 冷启动 | 新用户/物品无历史 | 内容特征、热门、探索 |
| 泄漏 | 使用点击后的特征 | point-in-time join |
| 反馈循环 | 头部越来越头部 | 探索、多样性、长期指标 |

## 横向：与其他技术的连接
- **与 ML/数据工程**：CTR 是典型表格学习，特征时间一致性决定可信度。
- **与 NLP/CV**：文本/图像 embedding 可解决内容召回与冷启动。
- **与 LLM**：可用于内容理解、解释和对话入口，不替代高吞吐召回排序。
- **与 RL/Bandit**：在线探索优化长期回报，但需要严格实验和风险控制。
- **与系统**：低延迟特征、ANN 索引和分层缓存是核心工程。

## 技术对比与选型
| 方法 | 优势 | 局限 | 适合 |
|---|---|---|---|
| 热门/规则 | 稳定可解释 | 不个性化 | 必保留 baseline |
| 协同过滤 | 利用交互结构 | 冷启动 | 交互密集场景 |
| 双塔召回 | 可离线建索引、规模大 | 交互较粗 | 大规模候选生成 |
| Cross/Deep Ranker | 精细特征交互 | 推理贵 | 小候选精排 |
| Bandit | 在线探索 | 评估与风险复杂 | 有成熟实验平台后 |

## Step by Step
1. 定义 impression、click、conversion 和预测时点，构建时间切分。
2. 实现热门/最近 baseline，再做 item/user CF。
3. 训练 matrix factorization，分析冷启动与长尾。
4. 构建双塔召回与负采样，测 Recall@K 和 ANN 延迟。
5. 训练排序模型，检查校准、AUC/NDCG 和关键 slice。
6. 加入多样性/新颖性重排，报告相关性取舍。
7. 设计 shadow/A-B 指标、guardrail 和停止条件。
8. 监控特征新鲜度、索引版本、延迟与反馈循环。

## 最小项目与验收标准
**项目：两阶段电影/商品推荐系统**
| 验收项 | 过关标准 |
|---|---|
| 数据 | 按时间切分，曝光与标签语义明确 |
| 基线 | 热门、协同、双塔至少三组 |
| 架构 | 召回与排序分开评测 |
| 质量 | Recall@K、NDCG、coverage 和长尾 slice |
| 服务 | ANN/排序延迟、索引和特征版本可追溯 |

## 常见误区与面试达标
- 误区：随机切分交互数据，或只看 AUC 不看召回和生态指标。
- 误区：把未点击当负反馈，忽略用户可能从未看到物品。
- 面试达标：能解释召回/排序、负采样、冷启动和曝光偏差。
