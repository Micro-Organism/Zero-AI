# 时序预测技术路线

> 一句话定位：围绕时间顺序、趋势季节性、外生变量、不确定性和回测建立预测闭环，严格避免未来信息泄漏。

## 快速概览
| 任务 | 输出 | 方法 | 指标 |
|---|---|---|---|
| Forecasting | 未来数值/区间 | naive、ARIMA、GBDT、DL | MAE/MASE/Pinball |
| Anomaly Detection | 异常点/区间 | 规则、残差、Autoencoder | PR-AUC/event F1 |
| Classification | 序列标签 | features、CNN/RNN/Transformer | Macro-F1 |
| Survival/Risk | 事件时间/风险 | survival models | C-index/calibration |

## 学习地图（表格）
| Step | 主题 | 必做实验 |
|---:|---|---|
| 1 | 时间语义 | frequency、timezone、missing、revision |
| 2 | 分解 | trend、seasonality、residual |
| 3 | Baseline | last value、seasonal naive、moving average |
| 4 | 统计模型 | ARIMA/ETS 状态与假设 |
| 5 | ML 特征 | lag/rolling/calendar、point-in-time |
| 6 | DL 模型 | RNN/TCN/Transformer 多步预测 |
| 7 | 回测 | rolling/expanding window、多 horizon |
| 8 | 部署 | forecast version、late data、drift/retrain |

## 核心技术要点与扩展谱系

| 层级 | 技术要点 | 解决的问题 | 前置知识 | 掌握标准 | 关联章节 |
|---|---|---|---|---|---|
| 必会 | trend/seasonality/autocorrelation、stationarity | 理解时间结构与统计假设 | 统计 | 能做分解、ACF 与残差诊断 | `02` |
| 必会 | naive/seasonal naive、ETS、ARIMA | 建立统计基线 | 时间序列基础 | 能做 rolling backtest 并解释参数 | `14` |
| 必会 | lag/rolling/calendar、GBDT | 将时序转成监督表格学习 | ML、数据工程 | 能保证 point-in-time 正确性 | `03`、`19` |
| 必会 | RNN/LSTM/GRU、seq2seq | 建模一般一维序列和多步输出 | [04 RNN](../01-基础与数据/04-神经网络与深度学习路线.md) | 能比较 recursive/direct 多步预测 | `04` |
| 进阶 | TCN、dilated causal convolution | 并行建模长历史 | CNN、causal mask | 能比较 receptive field 与 RNN | `04` |
| 进阶 | **ConvLSTM**：在 LSTM 输入、遗忘、输出门和状态更新中使用卷积 | 同时保留二维空间结构与时间记忆 | CNN、LSTM | 能实现单元、跟踪 `[B,T,C,H,W]` 并做网格预测 | [07 CV](./07-CV技术路线.md)、`05` |
| 进阶 | CNN+LSTM、3D CNN、PredRNN | 视频/雷达等时空预测 | CNN/RNN | 能比较特征后时序、局部时空卷积和记忆增强 | `07` |
| 进阶 | temporal/frequency Transformer：TFT、PatchTST 类 | 长依赖、多变量和已知协变量 | Attention | 能解释 patch、mask、horizon 与成本 | `08` |
| 进阶 | spatiotemporal GNN、DCRNN/STGCN 类 | 路网/传感器图上的时间传播 | GNN、RNN | 能建邻接图并评空间泛化 | `04`、`22` |
| 进阶 | probabilistic forecast、quantile/pinball、DeepAR 类 | 输出不确定性和多个可能未来 | 概率分布 | 能评 coverage、calibration、CRPS/Pinball | `02`、`14` |
| 了解 | time-series foundation model、Neural ODE、S4/Mamba 类 state space model | 大规模迁移与连续/长序列建模 | 预训练、微分方程/状态空间 | 能判断数据规模、复杂度和迁移边界 | `08-09`、`11` |

### ConvLSTM 与相邻方法怎么选

| 方法 | 空间建模 | 时间建模 | 优势 | 更适合 |
|---|---|---|---|---|
| CNN + LSTM | CNN 后压缩特征 | LSTM | 简单、模块清晰 | 空间细节可被压缩的序列 |
| 3D CNN | 3D kernel | 固定时间窗口卷积 | 并行、局部模式强 | 短视频分类/动作识别 |
| ConvLSTM | hidden/cell 保持网格 | 卷积门控递归 | 保留空间布局和长期状态 | 雷达回波、降水、视频帧预测 |
| TCN | 1D/可扩展空间编码 | 膨胀因果卷积 | 并行、稳定 receptive field | 一维或已编码时序 |
| PredRNN 类 | 时空记忆单元 | 多层递归记忆 | 专注视频预测 | 需要更强时空记忆的研究/实验 |
| 时空 GNN | 图消息传递 | RNN/TCN/Attention | 不规则空间拓扑 | 路网、传感器网络 |
| 时空 Transformer | patch/token attention | 全局 attention | 长依赖与多变量交互 | 数据/算力充足的大规模任务 |

## 纵向：从原理到交付的完整闭环
```text
预测时点/horizon -> 时间对齐/缺失 -> seasonal naive baseline
                 -> rolling backtest -> 统计/ML/DL 模型
                 -> 多 horizon/segment/区间评测 -> 发布
                 -> 实际值回填 -> drift/bias -> 重训
```
| 风险 | 错误 | 修复 |
|---|---|---|
| 未来泄漏 | centered rolling、全量归一化 | 只使用预测时可得信息 |
| 时间切分错 | random split | rolling-origin backtest |
| 预测修订 | 标签后来被修改 | 保存 as-of snapshot |
| 分布变化 | 节假日/政策/设备改变 | slice、外生变量、重训 |

## 横向：与其他技术的连接
- **与统计**：自相关、平稳性和区间估计提供诊断语言。
- **与 ML/DL**：树模型擅长人工 lag 特征，序列网络学习跨步表示。
- **与数据工程**：event time、迟到数据、重采样和 point-in-time 正确性是基础。
- **与业务**：horizon、更新频率和决策损失决定指标，不应只优化 RMSE。
- **与 MLOps**：预测值需要带 model/data/as-of version，实际值到达后自动回测。

## 技术对比与选型
| 方法 | 优势 | 局限 | 优先场景 |
|---|---|---|---|
| Seasonal Naive | 极强可解释基线 | 不利用复杂变量 | 所有项目第一步 |
| ARIMA/ETS | 小数据、结构明确 | 多序列/非线性弱 | 单/少量稳定序列 |
| GBDT + Lag | 表格特征与非线性强 | 特征工程多 | 有丰富外生变量 |
| RNN/TCN | 局部序列模式 | 长依赖/并行取舍 | 中等规模序列 |
| Transformer | 多序列/长上下文 | 数据和成本高 | 大规模、多变量 |

## Step by Step
1. 明确 forecast origin、horizon、frequency、timezone 与业务损失。
2. 画趋势、季节性、缺失、异常和 segment 分布。
3. 建立 last value 与 seasonal naive，作为不可跳过的基线。
4. 实现 rolling-origin backtest，所有预处理只 fit 训练窗口。
5. 比较统计模型与 GBDT lag/rolling 特征。
6. 数据规模足够再比较 RNN/TCN/Transformer。
7. 报告多 horizon、segment、峰值期和预测区间覆盖率。
8. 上线后按 as-of version 回填实际值并监控 bias/drift。

## 最小项目与验收标准
**项目：需求/流量多步预测服务**
| 验收项 | 过关标准 |
|---|---|
| 切分 | rolling backtest，无未来信息 |
| 基线 | seasonal naive 与至少两类模型 |
| 指标 | 多 horizon/segment + 区间或业务损失 |
| 版本 | 数据、预测时点、模型和实际值可追溯 |
| 监控 | bias、漂移、缺失和重训阈值明确 |

## 常见误区与面试达标
- 误区：随机切分、全量归一化、只在一个时间窗口评测。
- 误区：复杂模型没有打败 seasonal naive 仍上线。
- 面试达标：能解释 forecast origin、horizon、backtest 和 prediction interval。
