# 语音 AI 技术路线

> 一句话定位：从波形、频谱和声学表示进入 ASR、TTS、说话人和音频理解，并处理流式延迟、噪声、口音、隐私与主观质量评测。

## 快速概览
| 任务 | 输入 -> 输出 | 代表技术 | 指标 |
|---|---|---|---|
| ASR | speech -> text | CTC、Transducer、seq2seq | WER/CER/RTF |
| TTS | text -> speech | acoustic model、vocoder、codec LM | MOS/自然度/延迟 |
| Speaker | speech -> identity/embedding | speaker encoder | EER/minDCF |
| Audio Understanding | audio -> label/text | CNN/Transformer、audio-text | F1/mAP/retrieval |

## 学习地图（表格）
| Step | 主题 | 必做实验 |
|---:|---|---|
| 1 | 波形与采样 | sample rate、bit depth、channel |
| 2 | 频域表示 | STFT、mel spectrogram、augmentation |
| 3 | 音频数据 | 切分、VAD、转写、说话人隔离 |
| 4 | ASR | CTC/seq2seq、语言模型、解码 |
| 5 | TTS | text normalization、声学模型、vocoder |
| 6 | Speaker/Audio | embedding、分类、检索 |
| 7 | 评测 | 噪声/口音/长度 slice、MOS |
| 8 | 流式部署 | chunk、endpointing、RTF、并发 |

## 核心技术要点与扩展谱系

| 层级 | 技术要点 | 解决的问题 | 前置知识 | 掌握标准 | 关联章节 |
|---|---|---|---|---|---|
| 必会 | waveform、sample rate、STFT、mel spectrogram、MFCC | 将声音变成时频表示 | 信号/傅里叶直觉 | 能解释采样、窗和频谱分辨率 | `02` |
| 必会 | VAD、segmentation、speaker-level split、augmentation | 构造无泄漏音频数据 | 数据工程 | 能处理静音、噪声和说话人隔离 | `19` |
| 了解 | HMM-GMM、DNN-HMM hybrid ASR | 理解传统声学/发音/语言模型和对齐链路 | 概率、HMM | 能说明它与端到端 ASR 的模块化差异 | `06` |
| 必会 | CTC、beam search、language model fusion | 无显式对齐的语音识别 | RNN/Transformer | 能解释 blank、collapse 和 WER | `06` |
| 必会 | attention seq2seq、Transducer/RNN-T、streaming ASR | 序列转写与实时解码 | Seq2Seq、RNN | 能比较延迟、上下文和幻觉 | `06`、`15` |
| 进阶 | wav2vec 2.0/HuBERT/Whisper 类预训练 | 利用无标签/大规模语音表示 | 自监督、Transformer | 能做 frozen/finetune 对比 | `09`、`11` |
| 进阶 | speaker embedding、x-vector/ECAPA 类、diarization | 说话人识别和分离“谁在说” | CNN/统计 | 能评 EER/DER 并防 speaker 泄漏 | `07` |
| 进阶 | TTS acoustic model、Tacotron/FastSpeech 类、vocoder | 从文本生成可懂自然语音 | NLP、声谱 | 能区分声学模型和波形生成 | `08` |
| 进阶 | WaveNet/HiFi-GAN、neural codec、audio language model | 高质量波形/音频 token 生成 | CNN/GAN/自回归 | 能比较质量、速度和流式能力 | `08`、`13` |
| 了解 | speech enhancement/separation、audio-text model | 去噪、分离和音频语义理解 | DSP、多模态 | 能选择 SI-SDR、mAP、retrieval 指标 | `13`、`14` |

## 纵向：从原理到交付的完整闭环
```text
任务/语言/延迟 -> 音频许可/采样规范 -> VAD/切分/转写质检
              -> 预训练模型 baseline -> 迁移/微调 -> 分项评测
              -> streaming/batch serving -> 噪声/漂移/隐私监控
```
| 环节 | 风险 | 检查 |
|---|---|---|
| 数据 | 同说话人跨 split、录音未授权 | speaker-level split、consent |
| 预处理 | sample rate 不一致、截断 | 波形/频谱可视化 |
| ASR | 口音/噪声/专名退化 | CER/WER slice、热词集 |
| TTS | 音色冒用、主观质量差 | 授权、水印/披露、MOS |
| 服务 | chunk 边界丢字、延迟抖动 | RTF、endpoint latency、回归音频 |

## 横向：与其他技术的连接
- **与 DSP**：频谱、滤波、采样和信噪比是语音特有基础。
- **与 NLP/LLM**：ASR 输出进入 NLP；LLM 可做纠错/理解，但不能伪造原始转写证据。
- **与多模态**：audio-text 对齐与 CLIP 类对比学习共享思想。
- **与迁移学习**：预训练 speech encoder 后冻结、部分解冻或 PEFT 是常见路线。
- **与安全**：声音是生物特征，涉及授权、冒用、防伪和隐私保留。

## 技术对比与选型
| 对比 | 方案 | 优势 | 取舍 |
|---|---|---|---|
| Batch vs Streaming ASR | 完整音频/增量 chunk | 精度/实时 | 延迟与上下文 |
| CTC vs Seq2Seq | 条件独立/自回归 | 对齐简单/语言建模强 | 解码与幻觉 |
| 传统特征 vs Learned | mel/MFCC/原始或表示 | 可解释/端到端 | 数据与算力 |
| 云 API vs 自部署 | 快速/可控 | 运维低/隐私定制 | 成本与合规 |

## Step by Step
1. 读取并可视化波形、STFT 和 mel spectrogram，比较采样率。
2. 建立 VAD、切分、响度/长度统计和 speaker-level split。
3. 运行预训练 ASR，按噪声、口音、长度、专名报告 CER/WER。
4. 用领域数据微调或加热词/语言模型，保持同一回归集。
5. 跑一个 TTS baseline，评 text normalization、自然度和发音。
6. 做说话人或音频分类/检索实验，检查数据泄漏。
7. 模拟 streaming chunk，测 endpoint latency、RTF 和边界错误。
8. 加入授权、敏感音频保留、滥用防护和失败降级。

## 最小项目与验收标准
**项目：领域流式 ASR 服务**
| 验收项 | 过关标准 |
|---|---|
| 数据 | 授权、speaker split、转写质检完整 |
| 基线 | 预训练 vs 适配后同集比较 |
| 评测 | CER/WER + 噪声/口音/专名/长度 slice |
| 性能 | RTF、首结果、最终结果延迟与并发 |
| 安全 | 隐私、保留、访问、音色滥用边界明确 |

## 常见误区与面试达标
- 误区：随机切音频导致同一说话人跨集合，指标虚高。
- 误区：只看整体 WER，不听错误音频、不看实时边界。
- 面试达标：能解释采样、mel、CTC、WER/CER、VAD 与 streaming RTF。
