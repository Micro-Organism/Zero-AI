# 多模态技术路线

> 一句话定位：在 CV 与 LLM 基础上学习图文表示对齐、视觉语言模型、跨模态数据与评测；它是组合专项，不是初学 LLM 的前置条件。

## 快速概览

| 层次 | 核心问题 | 代表方法 | 产出 |
|---|---|---|---|
| 单模态编码 | 图像/音频如何变成表示 | ViT、CNN、audio encoder | modality embedding |
| 跨模态对齐 | 图文怎样进入共同空间 | CLIP、contrastive learning | 检索/zero-shot 能力 |
| 模态连接 | 视觉表示怎样供 LLM 使用 | projector、Q-Former、cross-attention | VLM 输入 token |
| 多模态生成 | 模型怎样理解并输出文本/媒体 | VLM、diffusion、audio models | 描述、问答、生成 |
| 系统交付 | 怎样评测、服务与防风险 | multimodal eval、batching、moderation | 可观测服务 |

## 学习地图（表格）

| Step | 主题 | 必做实验 |
|---:|---|---|
| 1 | 图像/文本预处理 | 检查 resize、crop、tokenization |
| 2 | Contrastive Learning | 实现 batch 内图文对比损失 |
| 3 | CLIP | zero-shot 分类与图文检索 |
| 4 | VLM 架构 | 跟踪 vision encoder -> projector -> LLM shape |
| 5 | 多模态 SFT | 检查 image placeholder、template、loss mask |
| 6 | 评测 | OCR、空间、计数、图表、幻觉切片 |
| 7 | 生成模型 | 了解 diffusion/flow 与 LLM 的连接 |
| 8 | 部署 | 图像限制、缓存、batch、GPU 与安全 |

## 核心技术要点与扩展谱系

| 层级 | 技术要点 | 解决的问题 | 前置知识 | 掌握标准 | 关联章节 |
|---|---|---|---|---|---|
| 必会 | vision/audio encoder、tokenizer、modality preprocessing | 把不同模态变成表示 | CV/NLP/语音 | 能跟踪输入到 embedding shape | `07`、`24` |
| 必会 | CLIP/dual encoder、contrastive loss、batch negatives | 图文对齐与高效检索 | 对比学习 | 能完成 zero-shot 和 Recall@K | `07`、`12` |
| 必会 | projector/adapter、image token、cross-attention | 将视觉特征连接到 LLM | Transformer | 能解释 connector 的信息瓶颈 | `08`、`11` |
| 必会 | VLM instruction tuning、multimodal template/loss mask | 学习图文指令行为 | SFT、VLM | 能检查 placeholder 与视觉幻觉 | `10`、`14` |
| 进阶 | Q-Former、Perceiver Resampler、early/late fusion | 压缩和融合跨模态信息 | Attention | 能比较融合位置和成本 | `08` |
| 进阶 | OCR/document AI、layout model、grounding | 理解版面、文本和区域对应 | CV/NLP | 能评 OCR、引用和坐标 grounding | `07`、`12` |
| 进阶 | diffusion/latent diffusion、ControlNet、Flow Matching | 条件图像/视频生成与控制 | 生成模型、CNN/ViT | 能解释去噪、latent 与条件注入 | `08` |
| 进阶 | VLA、action token、vision-language policy | 从视觉语言映射到行动 | 多模态、控制 | 能区分高层规划与低层控制 | `17` |
| 了解 | audio-language、video-language、3D-language model | 扩展到声音、视频和空间 | 对应单模态基础 | 能判断数据同步和评测难点 | `17`、`24` |

## 纵向：从原理到交付的完整闭环

```text
任务/模态定义 -> 数据许可/配对/标注 -> 单模态基线 -> 跨模态对齐
             -> projector/connector -> instruction tuning -> 分项评测
             -> 误差分析 -> 压缩/部署 -> 模态输入监控与安全治理
```

| 环节 | 多模态特有风险 | 检查方式 |
|---|---|---|
| 数据 | 图文错配、隐私肖像、版权 | 配对抽检、来源/许可登记 |
| 预处理 | crop 丢关键信息、OCR 尺寸不足 | 原图与输入张量可视化 |
| 对齐 | 捷径学习、负样本过易 | hard negative、跨域检索 |
| 指令微调 | image token/template 错位 | 解码样本、shape/loss mask 测试 |
| 评测 | 文本指标掩盖视觉幻觉 | 任务切片 + 人工 rubric |
| 部署 | 图片炸弹、恶意文件、显存波动 | 类型/尺寸限制、沙箱解析、监控 |

## 横向：与其他技术的连接

- **与 CV**：分类、检测、分割、OCR 和视觉 backbone 是感知基础。
- **与 LLM**：语言模型负责指令理解和生成，视觉 token 通过连接模块进入上下文。
- **与生成式 AI**：VLM 偏理解与文本输出；diffusion/flow 偏图像、视频或音频生成。
- **与迁移学习**：常先冻结视觉与语言 backbone，只训练 projector，再逐步 PEFT/解冻。
- **与 RAG**：多模态 RAG 需要解析图片、表格和版面，不能只提取纯文本。
- **与机器人**：VLA 把视觉、语言与动作连接，但还需控制、时序、安全和真实硬件闭环。

## 技术对比与选型

| 方法 | 训练目标 | 强项 | 典型用途 |
|---|---|---|---|
| CLIP 类双编码器 | 图文对比 | 检索快、zero-shot | 图文搜索、分类 |
| Cross-Encoder | 联合编码图文 | 交互细、精度高 | 重排、细粒度匹配 |
| VLM | 条件文本生成 | 问答、描述、文档理解 | 多模态助手 |
| Diffusion/Flow | 去噪/连续生成路径 | 媒体生成质量高 | 文生图/视频/音频 |
| VLA | 条件动作生成 | 感知语言到行动 | 机器人策略 |

| 适配方式 | 成本 | 适合 | 风险 |
|---|---:|---|---|
| 冻结双 backbone，只训 connector | 低 | 对齐冒烟、小数据 | 能力上限有限 |
| 视觉/语言侧 PEFT | 中 | 领域视觉或语言适配 | 模态能力不均衡 |
| 全量多模态微调 | 高 | 数据足、域差大 | 遗忘与训练不稳定 |

## Step by Step

1. 完成 [07-CV](./07-CV技术路线.md) 与 [08-大模型](./08-大模型与生成式AI路线.md) 的最低门禁。
2. 用预训练 CLIP 做 zero-shot 分类和图文检索，构造 hard negative。
3. 实现最小图文对比损失，理解 temperature 与 batch negatives。
4. 加载小型 VLM，跟踪图像预处理、视觉特征、projector 和语言 token shape。
5. 构建少量多模态指令数据，验证 placeholder、template、截断与 labels。
6. 按 OCR、空间关系、计数、细粒度属性、图表和视觉幻觉建立评测切片。
7. 用冻结 connector 与 PEFT 做对比，检查文本通用能力和视觉能力回归。
8. 包装服务，限制媒体类型/大小/分辨率，记录预处理、首 token 延迟和显存。

## 最小项目与验收标准

**项目：领域图片问答与图文检索系统**

| 验收项 | 过关标准 |
|---|---|
| 数据 | 图文配对、许可、隐私与 split 可审计 |
| 基线 | CLIP 检索与 VLM 问答分别评测 |
| 训练 | 至少比较 frozen connector 与一种 PEFT |
| 评测 | 含 OCR/空间/计数/幻觉切片和人工 rubric |
| 工程 | 媒体校验、预处理版本、显存/P95、失败降级 |
| 报告 | 明确视觉错误、语言错误和对齐错误的边界 |

## 常见误区与面试达标

- 误区：会调用 VLM API 就等于掌握多模态训练。
- 误区：只用 BLEU/ROUGE 评视觉问答，不检查视觉证据和幻觉。
- 误区：忽略 crop、分辨率和 image placeholder 对结果的影响。
- 面试达标：能解释 CLIP 对比学习、connector 与 cross-attention 的作用。
