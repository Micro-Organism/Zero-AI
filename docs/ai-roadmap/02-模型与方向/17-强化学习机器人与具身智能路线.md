# 强化学习、机器人与具身智能技术路线

> 一句话定位：区分强化学习方法、机器人学、自主系统与具身智能，在 ML/DL/PyTorch 之后补 MDP、仿真、感知-规划-控制、ROS 2 和真实环境安全闭环。

## 快速概览

| 层 | 核心内容 | 代表技术 | 前置 |
|---|---|---|---|
| RL 基础 | 状态、动作、奖励、回报 | MDP、Bellman、Q-learning | 概率、ML |
| Deep RL | 函数逼近与策略优化 | DQN、PPO、SAC | PyTorch、优化 |
| 仿真 | 可重复环境与数据 | Gymnasium、MuJoCo/Isaac Sim 类 | 物理/实验设计 |
| 机器人系统 | 感知、定位、规划、控制 | ROS 2、SLAM、MoveIt、PID/MPC | Linux、C++/Python |
| 学习型机器人 | 示范、强化、视觉语言动作 | imitation、offline RL、VLA | CV、多模态、控制 |

### 概念边界：机器人不完全等于具身智能

| 概念 | 核心定义 | 是否必须有物理身体 | 典型例子 |
|---|---|---:|---|
| 机器人学 Robotics | 研究机器的感知、定位、规划、控制和执行 | 通常是 | 机械臂、移动机器人、工业机器人 |
| 具身智能 Embodied AI | 智能体通过身体感知环境、采取动作，并从交互中学习或完成任务 | 物理或高保真仿真身体 | 人形机器人、操作机器人、仿真家务智能体 |
| 自主系统 Autonomous Systems | 在动态环境中自主感知、决策和控制，强调可靠性与安全 | 通常是 | 无人驾驶、无人机、无人船 |
| 强化学习 RL | 通过环境反馈优化长期回报的方法 | 否 | 游戏策略、资源调度、机器人策略 |
| 纯软件智能体 | 在数字环境中推理、规划或调用工具 | 否 | 围棋 AI、LLM Agent、交易策略 |

它们是交叉关系，不是简单包含关系：

- **机器人学比具身智能更宽**：固定程序控制的工业机械臂属于机器人学，但不一定具备学习和环境泛化能力。
- **具身智能强调闭环交互**：存在感知 -> 决策 -> 动作 -> 环境反馈，并受到身体、时空和物理约束。
- **无人驾驶和无人机**通常同时属于机器人学、自主系统，也可以视为具身智能的重要应用，但行业中常独立成“自动驾驶/自主飞行”技术栈。
- **围棋 AI**如果只是软件下棋程序，属于搜索、强化学习和决策智能，不属于典型具身智能；如果增加摄像头、机械臂和真实棋盘操作，整个系统包含具身部分，但围棋决策模型本身仍是软件智能。

### 典型具身与自主系统技术栈

| 场景 | 感知/状态估计 | 决策与规划 | 控制与执行 | 特有门禁 |
|---|---|---|---|---|
| 无人驾驶 | 摄像头/雷达融合、定位、预测 | 行为决策、轨迹规划 | 转向、制动、纵横向控制 | 功能安全、长尾场景、道路法规 |
| 无人机 | IMU/GNSS/视觉、姿态估计 | 航路与避障规划 | 飞控、姿态/位置控制 | 重量能耗、通信、失控保护 |
| 机械臂 | 视觉/力觉、位姿估计 | 抓取与运动规划 | 逆运动学、力/位置控制 | 碰撞、精度、人机协作 |
| 移动/人形机器人 | 多传感器、SLAM、人体/物体感知 | 导航、任务与动作规划 | 底盘/全身控制 | 平衡、实时性、开放环境 |
| 仿真具身智能体 | 模拟视觉/状态 | policy、VLA、层级规划 | 模拟动作 | sim-to-real 与评测真实性 |

## 核心技术要点与扩展谱系

| 层级 | 技术要点 | 解决的问题 | 前置知识 | 掌握标准 | 关联章节 |
|---|---|---|---|---|---|
| 必会 | MDP、Bellman、Monte Carlo、TD、Q-learning、exploration | 形式化序列决策并从经验估计价值 | 概率、优化 | 能实现动态规划、MC 与 tabular TD | `02-03` |
| 必会 | DQN、policy gradient、actor-critic、PPO/SAC | 用神经网络学习策略 | PyTorch、RL 基础 | 能多 seed 复现并诊断不稳定 | `05`、`14` |
| 必会 | coordinate/tf、kinematics、PID/MPC | 表示姿态并稳定控制运动 | 线代、控制基础 | 能建立经典控制 baseline | `02` |
| 必会 | ROS 2 node/topic/service/action/tf2/bag | 组织机器人分布式组件 | Linux、网络 | 能复现感知-规划-控制数据流 | `15` |
| 必会 | localization/SLAM、mapping、path/motion planning | 建图定位与安全运动 | CV、概率 | 能区分状态估计、全局/局部规划 | `07` |
| 进阶 | imitation/behavior cloning、offline RL、DAgger | 从示范和离线数据学习策略 | 监督学习/RL | 能分析分布偏移与数据覆盖 | `11` |
| 进阶 | world model、model-based RL、Dreamer 类 | 学习环境动态并在模型中规划 | 时序/生成模型 | 能解释 model bias 与 rollout | `23` |
| 进阶 | VLM/VLA、hierarchical planning、language-conditioned policy | 开放语言任务到动作 | 多模态、控制 | 能划分高层语义和低层实时控制 | `13` |
| 进阶 | sensor fusion、Kalman/particle filter、domain randomization | 多传感器估计与 sim-to-real | 概率、仿真 | 能评噪声、延迟和现实迁移 | `07`、`14` |
| 了解 | autonomous driving/drone stack、functional safety、HIL | 领域自主系统交付 | 机器人主干 | 能说明专用法规和安全门禁 | `20` |

## 纵向：从原理到交付的完整闭环

```text
任务/安全边界 -> 状态/动作/奖励定义 -> 仿真环境 -> 非学习控制基线
             -> 数据/示范 -> 策略训练 -> 多 seed/扰动评测
             -> 仿真集成 -> SIL/HIL -> 限速/急停/人工接管
             -> 小范围实机 -> 日志复盘 -> sim-to-real 迭代
```

| 环节 | 风险 | 验收 |
|---|---|---|
| 奖励 | reward hacking、稀疏或错目标 | 行为录像与分解 reward |
| 训练 | 高方差、seed 敏感 | 多 seed 均值/方差与曲线 |
| 仿真 | 物理与传感器过于理想 | domain randomization/扰动 |
| 控制 | 延迟、振荡、不稳定 | 频率、超调、稳态误差 |
| 实机 | 碰撞、越界、硬件损坏 | safety envelope、急停、审批 |

## 横向：与其他技术的连接

- **与监督学习**：imitation learning 从示范学策略；RL 通过环境反馈优化长期回报。
- **与 LLM 对齐**：PPO/GRPO 使用 RL 思想，但与物理机器人控制不是同一个工程栈。
- **与 CV/多模态**：视觉感知和 VLM/VLA 可提供状态或高层意图，不能替代实时控制与安全约束。
- **与经典控制**：PID/MPC 可解释、样本效率高，应作为基线或低层控制器。
- **与系统工程**：ROS 2 负责通信和组件协同，实时性、时钟、坐标系、日志与故障处理同样关键。
- **与仿真**：训练和测试先在仿真完成，但必须承认 sim-to-real gap。
- **与无人驾驶/无人机**：二者共享感知-预测-规划-控制闭环，但还需要领域法规、实时系统、功能安全和专用硬件，不能只靠通用机器人课程覆盖。

## 技术对比与选型

### RL 方法

| 方法 | 类型 | 优势 | 适用/限制 |
|---|---|---|---|
| Q-learning/DQN | value-based、off-policy | 概念直观、可复用数据 | 离散动作更自然 |
| PPO | on-policy policy optimization | 稳定常用、实现成熟 | 样本效率较低 |
| SAC | off-policy actor-critic | 连续控制、样本效率较好 | 实现和调参更复杂 |
| Imitation/BC | 监督式策略学习 | 利用专家示范、起步快 | 分布外误差累积 |
| Offline RL | 固定数据学策略 | 无需在线探索 | 分布外动作估值困难 |

### 机器人与具身方案

| 方案 | 优势 | 适合 | 不足 |
|---|---|---|---|
| 规则/状态机 | 可预测、易验证 | 固定流程 | 泛化有限 |
| 经典规划 + 控制 | 安全边界清晰、数据少 | 导航/机械臂基础 | 感知不确定性处理有限 |
| Learning Policy | 复杂映射与泛化潜力 | 难手工建模任务 | 数据、验证和安全成本高 |
| VLA/分层系统 | 语言任务到动作 | 开放指令与多任务 | 实时、安全、数据仍是难点 |

## Step by Step

1. 完成 `02-05` 门禁；用 GridWorld 实现动态规划和 tabular Q-learning。
2. 使用成熟环境库复现 DQN 或 PPO，记录多 seed、样本效率和失败录像。
3. 比较随机、规则/控制基线与学习策略，不只比较两个 RL 算法。
4. 补坐标变换、正/逆运动学、PID 与 MPC 基础。
5. 学 ROS 2 node、topic、service、action、tf2 和 bag，搭建仿真数据流。
6. 在仿真中完成感知 -> 规划 -> 控制闭环，加入延迟和传感器噪声。
7. 用示范做 behavioral cloning，再比较 RL fine-tuning 或 offline RL。
8. 实机前完成 safety envelope、急停、限速、SIL/HIL 与回滚方案。

## 最小项目与验收标准

**项目：仿真移动机器人导航或机械臂操作**

| 验收项 | 过关标准 |
|---|---|
| 基线 | 规则/经典控制与学习策略均有结果 |
| 训练 | 多 seed 曲线、成功率、样本效率和失败录像 |
| ROS 2 | topic/action/tf2/bag 结构清楚且可复现 |
| 鲁棒性 | 噪声、延迟、初始状态和场景扰动测试 |
| 安全 | 限速、边界、急停、人工接管和故障状态 |
| 报告 | 区分感知、规划、控制和策略错误 |

## 常见误区与面试达标

- 误区：只跑一个 seed、只看最高 reward，不看成功率和行为。
- 误区：直接上实机训练，跳过仿真、控制基线与安全门禁。
- 误区：认为 VLA 或 LLM 能替代坐标、运动学和实时控制。
- 面试达标：能解释 MDP、Bellman、on/off-policy、探索和 reward hacking。
- 面试达标：能画出 ROS 2 感知-规划-控制数据流和安全边界。
