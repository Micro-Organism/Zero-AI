# Zero-AI 项目结构总览

> 更新时间：2026-07-29  
> 仓库：`Zero-AI`（多模块 AI 实验 / 测试平台）

---

## 1. 项目定位

Zero-AI 是一个以 **Spring AI / Spring AI Alibaba** 与 **Python 微调学习** 并存的仓库，主要包含：

| 模块 | 角色 | 状态概览 |
|------|------|----------|
| `zero-ai-alibaba` | Spring AI Alibaba 智能体测试平台（前后端） | 功能较完整（Chat / Agent / RAG / MCP 等） |
| `zero-ai-boot` | 较早期的 Spring Boot + Spring AI 脚手架 | 体量小，偏启动验证 |
| **`zero-ai-study`** | **纯 Python 大模型微调学习工程（与 Spring AI 解耦）** | 已脚手架：Step 0～5 |
| `docs/` | 项目文档（结构说明、需求分析、学习计划） | 建设中 |
| `openspec/` | OpenSpec 变更驱动工作流配置 | 已初始化 |

根目录 `README.md` 目前几乎为空；Java 模块说明见 `zero-ai-alibaba/README.md`；微调学习见 `zero-ai-study/README.md`。

## 3. 主模块：`zero-ai-alibaba`

### 3.1 一句话说明

基于 **Spring Boot 3.5.9 + Spring AI Alibaba 1.1.0.0-RC2 + DashScope（阿里云百炼）**，配套 **Vue3 + Vite + Ant Design Vue** 前端的智能体能力测试平台。

### 3.2 目录树（核心）

```
zero-ai-alibaba/
├── pom.xml
├── README.md                          # 详细使用 / 测试 / 多智能体说明
├── 完整模块列表.md                    # 对官方 examples 模块的扫描清单
├── test-api.sh / test-api.bat         # API 冒烟脚本
├── test-dify-all-apps.sh              # Dify 相关测试脚本
├── frontend/                          # 前端（Vue3 + TS + Ant Design Vue）
├── src/main/java/.../alibaba/         # 后端业务代码
├── src/main/resources/                # 配置、mapper、static、template
├── src/test/                          # 测试
├── study/                             # 学习笔记 / 对比文档 / 示例资料
└── logs/                              # 运行日志
```

### 3.3 后端包结构

包名：`com.sdecloud.springai.alibaba`

```
alibaba/
├── ZeroAiAlibabaApplication.java      # 启动类
├── controller/                        # REST 控制器
│   ├── ChatController                 # 基础对话
│   ├── AgentController                # ReactAgent / 工具调用
│   ├── MultiAgentController           # 多智能体
│   ├── RagController                  # RAG
│   ├── McpController                  # MCP
│   ├── GraphController                # Graph 工作流
│   ├── MemoryController               # 记忆
│   ├── MultimodalController           # 多模态
│   ├── DifyController                 # Dify 对接
│   └── DifyAppConfigController        # Dify 应用配置
├── service/ + service/impl/           # 业务服务（与 controller 一一对应）
└── common/
    ├── config/                        # Agent / ChatModel / Redis / Web / MultiAgent / DifyTools 等
    ├── model/                         # 结构化输出模型（Weather / Location / Analysis 等）
    ├── tool/                          # Agent 工具（天气、位置）
    ├── domain/                        # 领域对象（如 DifyAppConfig）
    └── enums/                         # 枚举（如 ModelType）
```

### 3.4 后端能力矩阵（按 Controller）

| 能力 | Controller | Service | 说明 |
|------|------------|---------|------|
| 基础 Chat | ChatController | ChatService | ChatClient / 多模型配置 |
| Agent | AgentController | AgentService | ReactAgent、工具调用、对话线程 |
| 多智能体 | MultiAgentController | MultiAgentService | Supervisor / Sequential / AgentTool 等 |
| RAG | RagController | RagService | 检索增强（含 pgvector 依赖） |
| MCP | McpController | McpService | MCP Server/Client（WebFlux） |
| Graph | GraphController | GraphService | Graph 工作流 |
| Memory | MemoryController | MemoryService | 会话记忆（Redis / memory starter） |
| 多模态 | MultimodalController | MultimodalService | 图文等多模态 |
| Dify | DifyController / DifyAppConfigController | DifyService / DifyAppConfigService | 对接 Dify 应用 |

### 3.5 技术栈（后端）

- Java 17、Spring Boot 3.5.9、Web + WebFlux  
- Spring AI Alibaba：Agent Framework、DashScope Starter、Memory、Graph Core  
- Spring AI：DeepSeek、PgVector、MCP（Server/Client WebFlux）  
- Redis、PostgreSQL、Micrometer / Zipkin / Prometheus  

### 3.6 前端：`frontend/`

```
frontend/
├── package.json                       # zero-ai-alibaba-frontend
├── vite.config.ts
├── src/
│   ├── main.ts / App.vue
│   ├── api/                           # 与后端模块对应的 API 封装
│   ├── views/                         # Home / Chat / Agent / MultiAgent / Dify / Advanced
│   ├── components/advanced/           # RAG / MCP / Graph / Memory / Multimodal 测试组件
│   ├── router/ / stores/ / config/ / types/
└── debug/
```

技术栈：Vue 3.4、TypeScript、Vite 5、Vue Router、Pinia、Ant Design Vue 4、Axios、marked。

运行方式简述：

- **开发**：后端 `8080` + 前端 `pnpm run dev`（默认 `3000`，代理 `/api`）  
- **集成**：`pnpm run build*` 产物输出到 `src/main/resources/static`，由 Spring Boot 统一托管  

### 3.7 `study/` 学习资料

存放对比文档、博客、官方 examples 资料、Dify / 智能体 / 生态集成等学习内容，**不是运行时依赖**，适合查阅与扩展设计参考。

## 4. 次要模块：`zero-ai-boot`

### 4.1 定位

较早的 Spring Boot + Spring AI（OpenAI）启动工程，依赖 Spring Cloud Bootstrap、Actuator、部分 AI starter；代码量很少，偏脚手架验证。

### 4.2 结构

```
zero-ai-boot/
├── pom.xml                            # Spring Boot 3.3.4
├── HELP.md                            # Spring Initializr 生成帮助
└── src/main/java/com/zero/ai/
    ├── ZeroAiBootApplication.java
    └── controller/
        ├── AiController.java
        └── HealthController.java
```

与 `zero-ai-alibaba` **相互独立**（无根聚合 pom），按需单独启动。

## 6. 总体架构关系（示意）

```text
浏览器
  │
  ├─ 开发：Vite :3000 ──proxy /api──► Spring Boot :8080 (zero-ai-alibaba)
  └─ 集成：直接访问 :8080（static + API）

zero-ai-alibaba
  ├─ Controller 层（Chat / Agent / MultiAgent / RAG / MCP / Graph / Memory / Multimodal / Dify）
  ├─ Service 层
  ├─ Agent / Tool / Graph / Memory 配置
  └─ 外部：DashScope / DeepSeek / Redis / PG(Vector) / Dify / MCP

zero-ai-boot（独立）
  └─ 简单 AI + Health 接口（OpenAI 方向）

zero-ai-study（独立，纯 Python）
  └─ Step 0～5：概念 → 数据 → Unsloth 微调 → 评估 → 导出（Kaggle/Colab + HF）
```
